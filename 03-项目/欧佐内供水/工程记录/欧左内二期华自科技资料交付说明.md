# 欧左内二期华自科技资料交付说明

**自控厂家需提供以下电子版资料：**

1. **设备安装清单**  
   提供完整的设备安装明细表。

2. **使用说明书**  
   提供所有设备和元器件的详细使用说明书。

3. **图纸与线路设计**  
   包含以下图纸：  
   - 设备电气原理图  
   - 设备安装平面图  
   - 线路铺设及管线布置图

4. **设备访问密码**  
   提供设备的访问权限及密码信息，包括但不限于以下设备：  
   - 电脑  
   - 服务器  
   - 网关  
   - 摄像头  
   - 硬盘录像机  
   - 现场仪表

5. **控制程序**  
   提供包含以下内容的控制程序：  
   - **PLC 程序**  
   - **WinCC V8 SCADA 程序**  
   - **配电柜 HMI 程序**  
   程序需具备清晰的结构与详细的注释说明，特别是自定义控制块部分，需提供使用说明及访问密码。

6. **双语资料**  
   以上所有资料均需提供**中文**和**法文**两个版本。
