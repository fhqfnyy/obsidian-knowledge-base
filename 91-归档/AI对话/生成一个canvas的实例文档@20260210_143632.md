---

## ✅ 1. **Canvas（官方插件）**

这是 Obsidian 内置的可视化画布工具，支持拖拽节点、连接线、嵌入笔记、图片、代码块等。

### 安装方法：
1. 打开 Obsidian → 左侧边栏点击 **设置（齿轮图标）**
2. 选择 **社区插件**
3. 点击 **浏览社区插件**
4. 搜索 `Canvas`
5. 点击 **安装** → **启用**

> ✅ 该插件已内置在 Obsidian 1.0+ 版本中，无需额外下载。

---

## ✅ 2. **JSON View / JSON Editor 插件（用于查看/编辑 JSON）**

如果你是想在 Canvas 中**嵌入或编辑 JSON 数据**，可以安装以下插件：

### 推荐插件：
- **JSON View**（用于格式化显示 JSON）
- **JSON Editor**（用于编辑 JSON 数据）

### 安装方法：
1. 设置 → 社区插件 → 浏览社区插件
2. 搜索 `JSON View` 或 `JSON Editor`
3. 安装并启用
4. 在笔记中使用代码块：
   ```json
   {
     "name": "C#教程",
     "version": "1.0"
   }
   ```
   → 插件会自动格式化显示

---

## ❗ 注意：

- **Canvas 本身不支持直接“导入/导出 JSON 结构”**，但你可以：
  - 在 Canvas 节点中粘贴 JSON 文本
  - 使用“嵌入笔记”功能，将 JSON 文件作为子笔记嵌入
  - 通过脚本或 Dataview 插件动态生成 Canvas 内容（高级用法）

---

## 🚀 进阶建议：

如果你想**用 JSON 控制 Canvas 结构**（如自动生成节点、连接线），目前 Obsidian **不支持原生 JSON 导入 Canvas**，但你可以：

- 使用 **Dataview 插件** + 自定义脚本生成 Canvas 内容
- 使用 **Templater 插件** + 模板生成结构化 Canvas
- 关注社区插件更新，未来可能支持 JSON 导入

---

## 📌 总结：

| 你想要的功能 | 推荐插件 | 安装方式 |
|--------------|----------|----------|
| 使用可视化画布 | **Canvas（官方）** | 设置 → 社区插件 → 安装 |
| 查看/编辑 JSON | **JSON View / JSON Editor** | 同上 |
| 用 JSON 控制 Canvas | ❌ 暂不支持 | 可用 Dataview + 脚本替代 |
