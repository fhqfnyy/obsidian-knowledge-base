## 第4页：差分信号原理

### 差分传输的秘密

```
信号传输示意：
┌─────────────────────────────────────────────────────┐
│                                                      │
│   发送逻辑 "1"：                                      │
│   ┌──────┐      A线 ───► ════════════ 高电平 (+V)      │
│   │ 发送端├──────      B线 ───► ───────── 低电平 (0V)  │
│   └──────┘           电压差 = +V → 逻辑 "1"          │
│                                                      │
│   发送逻辑 "0"：                                      │
│   ┌──────┐      A线 ───► ───────── 低电平 (0V)        │
│   │ 发送端├──────      B线 ───► ════════════ 高电平(+V)│
│   └──────┘           电压差 = -V → 逻辑 "0"          │
│                                                      │
└─────────────────────────────────────────────────────┘
```

### 关键优势
- ✅ **双线传输**：使用 A/B 双线同时传输
- 🛡️ **共模噪声抵消**：噪声同时影响两根线，差分后消除
- ⚡ **低电压识别**：仅需 200mV 电压差即可识别信号

## 第9页：Modbus RTU 协议

### 最常用的 RS-485 应用协议

```
Modbus RTU 帧结构：

┌──────────┬─────────┬────────┬──────────┬────────┐
│ 起始符   │ 地址码  │ 功能码 │  数据    │ CRC校验│
│ (3.5字符)│ (1字节) │ (1字节)│ (N字节)  │ (2字节)│
└──────────┴─────────┴────────┴──────────┴────────┘
```

### 常用功能码

| 功能码 | 名称 | 说明 |
|--------|------|------|
| 0x01 | 读线圈 | 读取开关量输出 |
| 0x03 | 读保持寄存器 | 读取数据寄存器 |
| 0x05 | 写单个线圈 | 控制开关输出 |
| 0x06 | 写单个寄存器 | 写入数据 |
| 0x10 | 写多个寄存器 | 批量写入 |

### 📝 CRC-16 计算示例

```python
def calc_crc16(data):
    crc = 0xFFFF
    for byte in data:
        crc ^= byte
        for _ in range(8):
            if crc & 0x0001:
                crc = (crc >> 1) ^ 0xA001
            else:
                crc >>= 1
    return crc
```

## 第11页：常见问题与解决方案

### 故障排查指南

| 问题现象 | 可能原因 | 解决方案 |
|----------|----------|----------|
| ❌ **通信失败** | 终端电阻未接或接错 | 在总线两端安装 120Ω 电阻 |
| ❌ **数据错误** | A/B 极性接反 | 交换 A/B 线的连接 |
| ❌ **通信距离不足** | 信号衰减严重 | 降低波特率或使用中继器 |
| ❌ **节点时通时断** | 阻抗不匹配 | 检查终端电阻和网络拓扑 |
| ❌ **数据全部错误** | 波特率不匹配 | 确认主从设备波特率一致 |
| ❌ **部分节点不通** | 地址冲突 | 检查设备地址是否唯一 |

## 第12页：设计最佳实践

### ✅ 推荐做法

| 项目 | 建议 |
|------|------|
| **线缆选择** | 使用屏蔽双绞线 (STP)，如 Cat5e |
| **接地** | 确保所有设备共地 |
| **终端电阻** | 始终在总线两端安装 120Ω 电阻 |
| **布线** | 避免与电源线平行走线 |
| **屏蔽** | 屏蔽层单点接地 |
| **防雷** | 在户外环境中添加防雷保护 |

### ❌ 避免的错误

1. 不接终端电阻
2. A/B 线接反
3. 不同波特率设备混用
4. 线缆过长未考虑信号衰减
5. 设备不共地
