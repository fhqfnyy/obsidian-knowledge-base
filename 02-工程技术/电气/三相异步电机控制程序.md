## 🤖 Assistant

【功能说明】  
本程序为一个标准的三相异步电机控制功能块 (FB)，支持本地/远程启动/停止控制、急停保护、故障反馈、运行状态指示以及电机电流监测等功能。适用于工业现场常见的泵、风机等负载类型。

---

### ✅ 功能特性：

- 支持本地按钮与远程信号双路控制；
- 具备急停输入（常闭触点）、故障反馈（如热继电器动作）；
- 包含电机启动延时、禁止频繁启停机制；
- 提供运行状态、故障状态、电流监控输出；
- 可作为设备模块集成到更复杂的控制系统中；

---

```scl
// Motor Control Function Block - Standard 3-phase AC Motor with E-Stop and Fault Feedback

FUNCTION_BLOCK "FB_MotorControl"
{ S7_Optimized_Access := 'TRUE' }
VERSION : 0.1
   VAR_INPUT 
      En_LocalStart     : BOOL;       // Local Start Pushbutton (Normally Open)
      En_RemoteStart    : BOOL;       // Remote Start Command from SCADA/HMI/PLC
      En_Stop           : BOOL;       // Stop Command (Local or Remote)
      En_EmergencyStop  : BOOL := TRUE;  // Emergency Stop Input (Normally Closed, active low)
      En_FaultFeedback  : BOOL := TRUE;  // Fault Signal from Thermal Relay or VFD (Normally Closed, active low)

      In_MotorCurrent   : REAL;       // Analog input of motor current in Amps
      Para_StartDelay   : TIME := T#2S;  // Minimum time between stop to start command (anti-restart delay)
      Para_MaxCurrent   : REAL := 10.0;  // Max allowed current before overload warning (Amps)
   END_VAR

   VAR_OUTPUT 
      Out_RunRequest    : BOOL;        // Output signal to contactor or VFD enable
      Out_IsRunning     : BOOL;        // Indicates if motor is currently running
      Out_IsFaulted     : BOOL;        // Latchable fault status output
      Out_CurrentStatus : REAL;        // Filtered or sampled current value for HMI display
      Out_OverloadAlarm : BOOL;        // Overcurrent alarm flag
   END_VAR

   VAR 
      stat_LastStopTime     : TIME;      // Time when last stop occurred
      stat_DelayTimer       : TON_TIME;  // Timer for anti-restart delay
      stat_ResetTriggered   : BOOL;      // Used to latch reset logic
      stat_InternalRunCmd   : BOOL;
      stat_InternalFault    : BOOL;
   END_VAR

BEGIN

   // -----------------------------
   // STEP 1: Handle Emergency Stop and External Faults
   // -----------------------------

   // If E-Stop pressed or external fault detected, force shutdown immediately
   IF NOT En_EmergencyStop OR NOT En_FaultFeedback THEN
       stat_InternalRunCmd := FALSE;
       stat_InternalFault := TRUE;
   ELSE
       stat_InternalFault := FALSE;
   END_IF;

   // -----------------------------
   // STEP 2: Process Start Commands with Anti-Restart Delay
   // -----------------------------

   // Allow restart only after Para_StartDelay has elapsed since last stop
   stat_DelayTimer(IN:=En_Stop, PT:=Para_StartDelay);
   
   // Generate internal run command based on valid start conditions
   IF En_Stop THEN
       stat_LastStopTime := CURRENT_TIME();
       stat_InternalRunCmd := FALSE;
   ELSIF (NOT stat_DelayTimer.Q) AND (En_LocalStart OR En_RemoteStart) THEN
       stat_InternalRunCmd := TRUE;
   END_IF;

   // -----------------------------
   // STEP 3: Final Run Request Logic
   // -----------------------------

   Out_RunRequest := stat_InternalRunCmd AND NOT stat_InternalFault;

   // -----------------------------
   // STEP 4: Status Outputs
   // -----------------------------

   Out_IsRunning := Out_RunRequest;

   Out_IsFaulted := stat_InternalFault;

   Out_CurrentStatus := In_MotorCurrent;

   Out_OverloadAlarm := In_MotorCurrent > Para_MaxCurrent;

END_FUNCTION_BLOCK
```

## 【逻辑说明】

| 模块 | 描述 |
|------|------|
| **急停 & 故障检测** | 当 `En_EmergencyStop` 或 `En_FaultFeedback` 断开时，立即关闭电机输出并标记为故障状态 |
| **启停控制** | 使用本地按钮 (`En_LocalStart`) 和远程指令 (`En_RemoteStart`) 控制启停，并通过定时器防止短时间反复启停 |
| **状态输出** | 输出运行请求、是否正在运行、是否有故障及过载报警信息，可用于上位机显示 |

---

## 【注意事项】

- 所有输入应接线正确：急停和故障信号通常为“常闭”触点，在正常状态下保持闭合；
- 启动延迟参数可根据实际工艺需求调整；
- 若需支持自动复位功能，请增加额外复位按钮或逻辑判断；
- 建议将此功能块实例化后连接至真实数字输出模块（例如 DO8x24VDC）以驱动接触器或软起动器；
- 在大型系统中建议配合报警管理块进行集中报警处理；
