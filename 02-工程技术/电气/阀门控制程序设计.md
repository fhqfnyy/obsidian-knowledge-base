## 🤖 Assistant

【功能说明】
本功能块（FB）实现了一个完整的通用电动（或气动）阀门控制逻辑。
适用场合：调节阀或切断阀，具备 DO 输出控制开/关动作，DI 采集限位反馈，AI 采集模拟量开度反馈。
主要功能：
1.  **逻辑互锁**：防止开阀与关阀信号同时输出，保护执行机构电机。
2.  **超时保护**：动作超时未到位自动触发故障，防止电机长时间堵转烧毁。
3.  **信号诊断**：检测限位开关冲突（同时为真）、模拟量断线（超量程）。
4.  **模式切换**：支持仿真模式，便于调试。
5.  **状态监控**：提供阀门状态机及标准化的模拟量输出（0.0-100.0）。

```scl
FUNCTION_BLOCK "FB_ValveControl"
{ S7_Optimized_Access := 'TRUE' }
VERSION : 0.1

   VAR_INPUT 
      // 硬件信号输入
      bOpenLimitSwitch : Bool;       // 开到位限位开关 (I: 0=False/Unpressed, 1=True/Pressed)
      bCloseLimitSwitch : Bool;      // 关到位限位开关
      iPosFeedbackRaw : Int;         // 模拟量反馈原始值 (e.g., 0-27648 for 0-10V/4-20mA)
      iPosFeedbackRaw_High : Int := 27648; // 模拟量满量程上限，默认标准值
      
      // 控制命令输入
      bCmdOpen : Bool;               // 开阀命令 (Level Triggered, e.g., from HMI or Auto logic)
      bCmdClose : Bool;              // 关阀命令
      bEmgStop : Bool := FALSE;      // 急停信号 (True=Stop immediately)
      
      // 参数配置
      tActionTimeOut : Time := T#30S; // 动作超时时间 (根据阀门全行程时间设置)
      rSimPos : Real := 0.0;         // 仿真位置设定 (0.0 - 100.0)
      bSimMode : Bool := FALSE;      // 仿真模式使能
   END_VAR

   VAR_OUTPUT 
      // 硬件信号输出
      qOutOpen : Bool;               // 开阀输出 (Q: Relay 1)
      qOutClose : Bool;              // 关阀输出 (Q: Relay 2)
      
      // 状态反馈输出
      rPosNormalized : Real;         // 标准化开度反馈 (0.0 - 100.0)
      bIsOpened : Bool;              // 阀门全开状态 (Ready)
      bIsClosed : Bool;              // 阀门全关状态 (Ready)
      bFault : Bool;                 // 阀门故障总览
      wStatusCode : Word;            // 状态码 (用于SCADA诊断)
   END_VAR

   VAR 
      // 内部状态变量
      CurrentState : INT;            // 状态机当前状态
      // 状态定义: 0=Idle, 1=Opening, 2=Closing, 3=Fault
      
      myTimer : TON;                 // 超时计时器实例
      
      // 内部标志
      bFirstScan : Bool := TRUE;     // 首次扫描标志
      bFeedbackError : Bool;         // 反馈信号故障
      rPosInternal : Real;           // 内部处理用的位置值
   END_VAR

   VAR CONSTANT 
      // 状态码定义 - 方便SCADA读取
      STATUS_IDLE       : UInt := 16#0000;
      STATUS_OPENING    : UInt := 16#0001;
      STATUS_CLOSING    : UInt := 16#0002;
      STATUS_FAULT      : UInt := 16#FFFF;
      STATUS_TIMEOUT    : UInt := 16#1001;
      STATUS_SIG_CONFLICT : UInt := 16#1002; // 开关限位同时触发
   END_VAR

BEGIN
   // ***************************************************************************
   // 1. 初始化与信号处理
   // ***************************************************************************
   IF bFirstScan THEN
       CurrentState := 0; // Idle
       bFirstScan := FALSE;
   END_IF;

   // 模拟量标准化处理
   IF bSimMode THEN
       // 仿真模式：直接使用设定值
       rPosInternal := rSimPos;
       // 在仿真模式下强制限位反馈 (为了测试逻辑)
       IF rSimPos >= 99.5 THEN
           bOpenLimitSwitch := TRUE;
           bCloseLimitSwitch := FALSE;
       ELSIF rSimPos <= 0.5 THEN
           bOpenLimitSwitch := FALSE;
           bCloseLimitSwitch := TRUE;
       ELSE
           bOpenLimitSwitch := FALSE;
           bCloseLimitSwitch := FALSE;
       END_IF;
   ELSE
       // 真实模式：将模拟量转换为百分比 (0.0 - 100.0)
       // 增加简单的限幅防止除零或溢出
       IF iPosFeedbackRaw_High <> 0 THEN
           rPosInternal := (REAL_TO_INT(iPosFeedbackRaw) * 100.0) / REAL_TO_INT(iPosFeedbackRaw_High);
       ELSE
           rPosInternal := 0.0;
       END_IF;
       
       // 模拟量物理范围限制 (0-100%)
       IF rPosInternal > 100.0 THEN rPosInternal := 100.0; END_IF;
       IF rPosInternal < 0.0 THEN rPosInternal := 0.0; END_IF;
   END_IF;
   
   // 更新输出模拟量
   rPosNormalized := rPosInternal;

   // ***************************************************************************
   // 2. 安全逻辑与故障检测
   // ***************************************************************************
   bFeedbackError := FALSE;
   
   // 2.1 限位开关冲突检测 (硬线故障)
   IF bOpenLimitSwitch AND bCloseLimitSwitch THEN
       bFeedbackError := TRUE;
       wStatusCode := STATUS_SIG_CONFLICT;
   END_IF;

   // 2.4 急停处理
   IF bEmgStop THEN
       CurrentState := 3; // 跳转到故障态
       qOutOpen := FALSE;
       qOutClose := FALSE;
       RETURN; 
   END_IF;

   // ***************************************************************************
   // 3. 状态机主逻辑
   // ***************************************************************************
   CASE CurrentState OF
      // -----------------------------------------------------
      // 状态 0: 空闲
      // -----------------------------------------------------
      0: // Idle
         wStatusCode := STATUS_IDLE;
         qOutOpen := FALSE;
         qOutClose := FALSE;
         
         // 无故障且无命令时，如果有反馈故障，仍进入故障态
         IF bFeedbackError THEN
             CurrentState := 3;
         END_IF;
         
         // 命令处理 (简单互锁)
         IF bCmdOpen AND NOT bCmdClose AND NOT bOpenLimitSwitch THEN
             CurrentState := 1; // Go to Opening
             myTimer(IN:=FALSE, PT:=tActionTimeOut); // Reset Timer
         ELSIF bCmdClose AND NOT bCmdOpen AND NOT bCloseLimitSwitch THEN
             CurrentState := 2; // Go to Closing
             myTimer(IN:=FALSE, PT:=tActionTimeOut); // Reset Timer
         END_IF;

      // -----------------------------------------------------
      // 状态 1: 开阀中
      // -----------------------------------------------------
      1: // Opening
         wStatusCode := STATUS_OPENING;
         
         // 动作输出
         qOutOpen := TRUE;
         qOutClose := FALSE;
         
         // 启动超时计时
         myTimer(IN:=TRUE, PT:=tActionTimeOut);
         
         // 停止条件 1: 到位
         IF bOpenLimitSwitch THEN
             CurrentState := 0; // Back to Idle
             qOutOpen := FALSE; // 立即停止
             myTimer(IN:=FALSE);
         END_IF;
         
         // 停止条件 2: 命令取消 (可选，看工艺要求，这里设计为取消命令即停止)
         IF NOT bCmdOpen THEN
             CurrentState := 0;
             qOutOpen := FALSE;
             myTimer(IN:=FALSE);
         END_IF;
         
         // 停止条件 3: 故障
         IF bFeedbackError OR myTimer.Q THEN
             IF myTimer.Q THEN wStatusCode := STATUS_TIMEOUT; END_IF;
             CurrentState := 3; // Go to Fault
             qOutOpen := FALSE; // 安全停止
         END_IF;

      // -----------------------------------------------------
      // 状态 2: 关阀中
      // -----------------------------------------------------
      2: // Closing
         wStatusCode := STATUS_CLOSING;
         
         // 动作输出
         qOutOpen := FALSE;
         qOutClose := TRUE;
         
         // 启动超时计时
         myTimer(IN:=TRUE, PT:=tActionTimeOut);
         
         // 停止条件 1: 到位
         IF bCloseLimitSwitch THEN
             CurrentState := 0; // Back to Idle
             qOutClose := FALSE;
             myTimer(IN:=FALSE);
         END_IF;
         
         // 停止条件 2: 命令取消
         IF NOT bCmdClose THEN
             CurrentState := 0;
             qOutClose := FALSE;
             myTimer(IN:=FALSE);
         END_IF;

         // 停止条件 3: 故障
         IF bFeedbackError OR myTimer.Q THEN
             IF myTimer.Q THEN wStatusCode := STATUS_TIMEOUT; END_IF;
             CurrentState := 3; // Go to Fault
             qOutClose := FALSE;
         END_IF;

      // -----------------------------------------------------
      // 状态 3: 故障
      // -----------------------------------------------------
      3: // Fault
         wStatusCode := STATUS_FAULT;
         bFault := TRUE; // 锁定故障输出
         qOutOpen := FALSE;
         qOutClose := FALSE;
         myTimer(IN:=FALSE); // 停止计时
         
         // 故障复位逻辑
         // 1. 必须没有反馈硬故障
         // 2. 命令必须撤除 (防止复位后立刻继续动作)
         // 3. 再次按下命令信号作为复位触发 (或者增加专门的复位位，这里利用命令撤除作为软复位条件)
         IF NOT bFeedbackError AND NOT bCmdOpen AND NOT bCmdClose THEN
             CurrentState := 0; // Auto Reset to Idle
             bFault := FALSE;
         END_IF;

   ELSE
      // 未知状态处理
      CurrentState := 3;
   END_CASE;

   // ***************************************************************************
   // 4. 状态输出更新 (优化SCADA读取)
   // ***************************************************************************
   // 逻辑：只有在非故障态，且物理开关触发时，才认为真
   bIsOpened := bOpenLimitSwitch AND (NOT bFault);
   bIsClosed := bCloseLimitSwitch AND (NOT bFault);

END_FUNCTION_BLOCK
```

---

【逻辑说明】

1.  **状态机架构**：
    *   程序采用标准的CASE语句实现4态状态机：`Idle` (静止), `Opening` (开启中), `Closing` (关闭中), `Fault` (故障)。
    *   这种结构保证了在同一扫描周期内，阀门只能处于一种确定的状态，避免了双线圈输出风险和逻辑竞争。

2.  **输入处理与仿真**：
    *   模拟量输入 `iPosFeedbackRaw` 在内部被换算为 `0.0 - 100.0` 的浮点数，方便 SCADA 直接显示和 PID 模块调用。
    *   增加了 `bSimMode`（仿真模式）。当该位为 TRUE 时，程序忽略物理限位和模拟量输入，改用内部逻辑模拟开关动作，极大方便了不具备硬件条件时的逻辑验证。

3.  **故障保护机制**：
    *   **硬件互锁**：代码中严格判断 `bOpenLimitSwitch` 与 `bCloseLimitSwitch`，如果两个信号同时为 1，立即判定为线路短路或传感器故障，进入 Fault 态并切断输出。
    *   **动作超时**：使用 TON 定时器监控开阀和关阀过程。如果在设定时间内（例如 30秒）未收到到位信号，触发超时故障，防止电机因机械卡堵而烧毁。
    *   **急停响应**：`bEmgStop` 拥有最高优先级，一旦激活立即复位输出并进入故障态。

4.  **控制行为**：
    *   支持“点动”式控制（命令维持则动作，命令撤销则停止）。在 Opening/Closing 状态下，如果 `bCmdOpen` / `bCmdClose` 变为 FALSE，阀门会停止在当前位置。

【注意事项】

1.  **变量类型匹配**：
    *   确保 TIA Portal 硬件配置中，模拟量输入模块的量程设置（如 0-27648 对应 0-10V）与 `iPosFeedbackRaw_High` 常数一致。
    *   如果是 4-20mA 信号，通常需要“断线检测”功能，建议模拟量硬件组态中启用超限诊断，并通过硬件中断或 OB82 读取，本例主要处理逻辑故障。

2.  **输出接线**：
    *   对于电动执行机构，通常需要“惯性保护”。如果执行机构内部继电器响应较慢，PLC 输出脉冲过短可能导致接触器吸合不实。本程序在 OB1 周期性执行，输出会保持多个周期，通常足以驱动普通继电器。若现场有特殊要求（如脉冲型控制），需在 Output 端增加微型脉冲延时逻辑。

3.  **超时时间设定**：
    *   `tActionTimeOut` 必须大于阀门的全行程时间（Valve Full Stroke Time）。建议设定为 `(全行程时间 * 1.2) + 5秒`，留出余量。

【可扩展建议】

1.  **模拟量死区处理**：
    *   在实际工况中，阀门全关时模拟量可能不为 0（例如 0.5%），全开时可能不为 100。可以在 VAR 中增加 `rDeadZone` 参数，在判断 `bIsOpened` 时结合模拟量进行软件滤波，减少限位开关频繁抖动带来的状态闪烁。

2.  **PID 闭环调节扩展**：
    *   如果该阀门用于调节流量，可以将此 FB 放置在底层，仅负责开/关保护。上层调用“PID_Compact” FB，将 PID 的 `LMN_PER`（模拟量输出）作为此 FB 的 `rSimPos`（如果是模拟量定位阀）或将 PID 输出与 DO 配合进行断续控制。

3.  **长期数据归档**：
    *   增加 `VAR_IN_OUT` 的统计接口，如 `dwCycleCounter`（动作次数累计）、`tTotalRunTime`（电机运行时间累计），用于预测性维护。
