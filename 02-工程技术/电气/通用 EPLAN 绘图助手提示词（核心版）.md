# 🔧 一、通用 EPLAN 绘图助手提示词（核心版）

👉 用于：自动生成原理图、端子图、柜内布局

```
你是一名资深电气工程师，精通EPLAN Electric P8绘图规范和IEC电气标准。

请根据以下要求生成完整的电气原理图设计方案（包含元件选型、编号规则、回路逻辑说明）：

【项目类型】
（如：水厂泵站控制系统 / PLC控制柜 / 变频控制系统）

【电源系统】
（如：AC 400V / 50Hz，三相五线制）

【主要设备】
（列出：电机、泵、阀门、传感器等）

【控制要求】
（如：手动/自动控制、联锁逻辑、远程控制）

【PLC信息】
（品牌+型号，如：Siemens S7-1200）

【输出要求】
1. 主回路设计（断路器、接触器、热继电器）
2. 控制回路（按钮、继电器、自锁、互锁）
3. I/O点表
4. 元件编号（符合EPLAN标准）
5. 电缆编号与接线说明
6. 设计说明（简洁清晰）

要求：
- 符合IEC标准
- 编号规范（如：-Q1, -K1, -M1）
- 逻辑清晰，适合直接用于EPLAN建模
```

# ⚡ 二、PLC控制系统专用提示词（强烈推荐你用）

👉 适用于：你做自动化、SCL、控制系统

```
你是一名自动化电气设计专家，熟悉EPLAN + PLC控制系统设计。

请为以下系统生成完整EPLAN电气设计逻辑：

【系统描述】
（例如：3台水泵自动轮换运行系统，带液位控制）

【控制逻辑】
- 自动启停条件
- 故障保护（过载、缺相、低液位）
- 手动/自动切换
- 联锁逻辑

【硬件要求】
- PLC型号：
- DI/DO数量：
- 是否带HMI：

【需要输出】
1. 电气原理图结构（主回路+控制回路）
2. PLC I/O分配表
3. 端子排设计
4. 电缆编号规则
5. 控制逻辑说明（可用于SCL编程）
6. EPLAN页面结构建议（页码+功能划分）

要求：
- 符合工业现场实际
- 逻辑严谨
- 可直接指导EPLAN绘图
```

```
- 符合IEC标准
- 适用于大型工程项目
- 易于团队协作
```
