在 MATLAB 中，数组和矩阵操作是非常重要的，因为 MATLAB 是一种面向矩阵计算的语言。以下是一些常见的数组和矩阵操作：

### 1. 创建数组和矩阵

#### 创建行向量：

```matlab
row_vector = [1, 2, 3, 4, 5];
```

#### 创建列向量：

```matlab
column_vector = [1; 2; 3; 4; 5];
```

#### 创建矩阵：

```matlab
matrix = [1, 2, 3; 4, 5, 6; 7, 8, 9];
```

### 2. 访问元素

#### 访问数组/矩阵元素：

```matlab
element = matrix(2, 3); % 获取矩阵 matrix 的第二行第三列的元素
```

### 3. 矩阵运算

#### 转置：

```matlab
transpose_matrix = matrix'; % 转置矩阵
```

#### 矩阵乘法：

```matlab
result = matrix1 * matrix2; % 矩阵相乘
```

#### 矩阵相加、相减：

```matlab
sum_matrix = matrix1 + matrix2; % 矩阵相加
difference_matrix = matrix1 - matrix2; % 矩阵相减
```

#### 元素级乘法、除法：

```matlab
elementwise_product = matrix1 .* matrix2; % 元素级乘法
elementwise_division = matrix1 ./ matrix2; % 元素级除法
```

### 4. 矩阵运算函数

#### 矩阵乘积：

```matlab
product = prod(matrix); % 矩阵中所有元素的乘积
```

#### 矩阵求和：

```matlab
matrix_sum = sum(matrix); % 矩阵中所有元素的和
```

#### 矩阵平均值：

```matlab
matrix_mean = mean(matrix); % 矩阵中所有元素的平均值
```

#### 矩阵最大值、最小值：

```matlab
matrix_max = max(matrix); % 矩阵中所有元素的最大值
matrix_min = min(matrix); % 矩阵中所有元素的最小值
```

### 5. 特殊矩阵

#### 单位矩阵：

```matlab
identity_matrix = eye(3); % 3x3 的单位矩阵
```

#### 零矩阵：

```matlab
zero_matrix = zeros(2, 2); % 2x2 的零矩阵
```

#### 对角矩阵：

```matlab
diagonal_matrix = diag([1, 2, 3]); % 以数组的对角线元素创建对角矩阵
```

这些是 MATLAB 中常见的数组和矩阵操作。熟练掌握这些操作可以让你更高效地处理和计算数据。
