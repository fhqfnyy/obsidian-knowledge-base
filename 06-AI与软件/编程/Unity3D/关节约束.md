以下是一个简单的示例程序，演示如何在Unity中使用关节约束来创建两个物体之间的连接：

```csharp
using UnityEngine;

public class JointConstraintExample : MonoBehaviour
{
    // 定义连接的两个物体
    public Rigidbody connectedBody1;
    public Rigidbody connectedBody2;

    // 定义连接点和旋转轴
    public Vector3 anchor;
    public Vector3 axis;

    void Start()
    {
        // 创建关节约束
        ConfigurableJoint joint = gameObject.AddComponent<ConfigurableJoint>();

        // 设置连接的两个刚体
        joint.connectedBody = connectedBody1;

        // 设置连接点和旋转轴
        joint.anchor = anchor;
        joint.axis = axis;

        // 设置连接方式为自由旋转
        joint.xMotion = ConfigurableJointMotion.Free;
        joint.yMotion = ConfigurableJointMotion.Free;
        joint.zMotion = ConfigurableJointMotion.Free;

        // 锁定旋转轴
        joint.angularXMotion = ConfigurableJointMotion.Locked;
        joint.angularYMotion = ConfigurableJointMotion.Locked;
        joint.angularZMotion = ConfigurableJointMotion.Locked;
    }
}
```

在这个示例中：

- 在 `Start()` 方法中创建了一个 `ConfigurableJoint` 组件，并将其添加到当前游戏对象上。
- 设置了连接的两个刚体对象 `connectedBody1` 和 `connectedBody2`。
- 设置了连接点 `anchor` 和旋转轴 `axis`。连接点是相对于当前游戏对象的局部坐标的位置，旋转轴是连接点的旋转轴方向。
- 设置了连接方式为自由旋转，即连接的物体可以在三个轴向上自由旋转。
- 锁定了旋转轴，防止连接的物体在这些轴向上旋转。

这个示例演示了如何使用关节约束来创建两个物体之间的连接，并限制它们的旋转行为，从而实现特定的物理效果。
