下面是一个简单的示例程序，演示如何在Unity中使用触发器（Trigger）：

```csharp
using UnityEngine;

public class TriggerExample : MonoBehaviour
{
    void OnTriggerEnter(Collider other)
    {
        // 当进入触发器时触发的逻辑
        Debug.Log("Entered trigger with: " + other.gameObject.name);
    }

    void OnTriggerExit(Collider other)
    {
        // 当离开触发器时触发的逻辑
        Debug.Log("Exited trigger with: " + other.gameObject.name);
    }
}
```

在这个示例中：

- 当其他游戏对象进入触发器时，`OnTriggerEnter(Collider other)` 方法会被调用。`other` 参数是进入触发器的游戏对象的 Collider 组件。
- 当其他游戏对象离开触发器时，`OnTriggerExit(Collider other)` 方法会被调用。`other` 参数是离开触发器的游戏对象的 Collider 组件。

要使用这个示例，只需将该脚本附加到带有 Collider 组件的游戏对象上，并确保该 Collider 组件被设置为触发器（Is Trigger 勾选）。然后，当其他游戏对象进入或离开触发器时，上述方法将被调用，并执行相应的逻辑。
