下面是一个简单的示例，演示如何使用鼠标控制摄像机的视角。这个示例中，摄像机围绕目标对象旋转，以模拟第三人称视角控制。

```csharp
using UnityEngine;

public class CameraControl : MonoBehaviour
{
    // 目标对象
    public Transform target;

    // 旋转速度
    public float rotationSpeed = 5f;

    // 最小和最大俯仰角度
    public float minPitch = -30f;
    public float maxPitch = 60f;

    // 初始相对距离
    public float distance = 5f;

    // 鼠标灵敏度
    public float mouseSensitivity = 2f;

    // 当前水平和垂直旋转角度
    private float yaw = 0f;
    private float pitch = 0f;

    void Start()
    {
        // 初始化摄像机位置
        transform.position = target.position - transform.forward * distance;
    }

    void Update()
    {
        // 获取鼠标输入
        float mouseX = Input.GetAxis("Mouse X") * mouseSensitivity;
        float mouseY = Input.GetAxis("Mouse Y") * mouseSensitivity;

        // 更新水平和垂直旋转角度
        yaw += mouseX * rotationSpeed;
        pitch -= mouseY * rotationSpeed;
        pitch = Mathf.Clamp(pitch, minPitch, maxPitch);

        // 计算旋转角度
        Quaternion rotation = Quaternion.Euler(pitch, yaw, 0f);

        // 更新摄像机位置和旋转
        transform.position = target.position - rotation * Vector3.forward * distance;
        transform.rotation = rotation;
    }
}
```

在这个示例中：

- `target` 是摄像机要围绕旋转的目标对象。
- `rotationSpeed` 是摄像机旋转的速度。
- `minPitch` 和 `maxPitch` 是摄像机俯仰角的最小和最大值，限制了摄像机的俯仰角度。
- `distance` 是摄像机与目标对象之间的初始距离。
- `mouseSensitivity` 是鼠标灵敏度，控制了鼠标移动时摄像机旋转的速度。
- `yaw` 和 `pitch` 是当前的水平和垂直旋转角度。
- `Start()` 方法用于初始化摄像机的位置，将摄像机放置在目标对象的背后一定距离处。
- `Update()` 方法每帧被调用，用于更新摄像机的位置和旋转。
- `Input.GetAxis("Mouse X")` 和 `Input.GetAxis("Mouse Y")` 获取鼠标在水平和垂直方向上的移动。
- 通过更新 `yaw` 和 `pitch` 角度来响应鼠标输入，并使用 `Mathf.Clamp()` 方法限制了垂直旋转角度的范围。
- 使用 `Quaternion.Euler()` 构造旋转角度，然后根据该角度更新摄像机的位置和旋转。

将这个脚本挂载到摄像机上，然后将目标对象指定为 `target`。然后，在游戏中移动鼠标，摄像机就会围绕目标对象进行旋转，实现第三人称视角控制。
