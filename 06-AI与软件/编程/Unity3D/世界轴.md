以下是一个简单的示例代码，演示如何使用世界坐标系中的轴来对游戏对象进行旋转：

```csharp
using UnityEngine;

public class WorldAxisRotationExample : MonoBehaviour
{
    // 旋转速度
    public float rotationSpeed = 50f;

    void Update()
    {
        // 计算旋转角度
        float angle = rotationSpeed * Time.deltaTime;

        // 使用世界坐标系中的轴来旋转，这里以 Y 轴为例
        transform.Rotate(Vector3.up, angle, Space.World);
    }
}
```

在这个示例中：

- `rotationSpeed` 定义了旋转的速度，单位是度/秒。
- `Update()` 方法每帧被调用，用于更新游戏对象的旋转。
- 使用 `transform.Rotate()` 方法来绕世界坐标系中的轴进行旋转，其中 `Vector3.up` 表示 Y 轴，`angle` 表示每帧旋转的角度。
- `Space.World` 参数告诉 Unity 使用世界坐标系中的轴来进行旋转。

通过修改 `rotationSpeed` 可以控制旋转的速度，从而实现不同的旋转效果。
