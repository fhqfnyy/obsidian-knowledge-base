下面是一个简单的示例，演示如何使用键盘控制一个对象的运动。这个示例假设你想在水平平面上移动一个物体。

```csharp
using UnityEngine;

public class MovementControl : MonoBehaviour
{
    // 移动速度
    public float moveSpeed = 5f;

    void Update()
    {
        // 获取键盘输入
        float horizontalInput = Input.GetAxis("Horizontal");
        float verticalInput = Input.GetAxis("Vertical");

        // 计算移动方向
        Vector3 moveDirection = new Vector3(horizontalInput, 0f, verticalInput).normalized;

        // 计算移动距离
        float distance = moveSpeed * Time.deltaTime;

        // 移动物体
        transform.Translate(moveDirection * distance);
    }
}
```

在这个示例中：

- `moveSpeed` 定义了物体的移动速度。
- `Update()` 方法每帧被调用，用于更新物体的位置。
- `Input.GetAxis("Horizontal")` 和 `Input.GetAxis("Vertical")` 获取水平和垂直方向上的输入，通常对应于键盘上的方向键或者游戏手柄的摇杆。
- `new Vector3(horizontalInput, 0f, verticalInput).normalized` 构造了一个单位向量，表示物体在水平平面上的移动方向。水平方向输入控制物体的 X 轴移动，垂直方向输入控制物体的 Z 轴移动，Y 轴移动被忽略。
- `moveSpeed * Time.deltaTime` 计算了物体每帧应该移动的距离，乘以 `Time.deltaTime` 可以使得移动速度与帧率无关。
- `transform.Translate(moveDirection * distance)` 移动了物体，`moveDirection * distance` 表示物体每帧应该移动的位移量。

将这个脚本挂载到一个物体上，然后在游戏中按下方向键，这个物体就会沿着水平平面上的方向移动。
