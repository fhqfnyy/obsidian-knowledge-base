下面是一个简单的示例代码，演示如何使用Vector3来实现对象的运动和移动：

```csharp
using UnityEngine;

public class ObjectMovement : MonoBehaviour
{
    // 定义速度变量
    public float moveSpeed = 5f;

    void Update()
    {
        // 获取当前位置
        Vector3 currentPosition = transform.position;

        // 获取用户输入
        float horizontalInput = Input.GetAxis("Horizontal");
        float verticalInput = Input.GetAxis("Vertical");

        // 计算移动方向
        Vector3 moveDirection = new Vector3(horizontalInput, 0f, verticalInput).normalized;

        // 更新位置
        currentPosition += moveDirection * moveSpeed * Time.deltaTime;

        // 更新游戏对象的位置
        transform.position = currentPosition;
    }
}
```

在这个示例中：

- `Update()` 方法每帧都会被调用，用于更新游戏对象的位置。
- `Input.GetAxis("Horizontal")` 和 `Input.GetAxis("Vertical")` 用于获取水平和垂直方向上的用户输入。这些输入值可以通过键盘、手柄等设备来获取。
- 创建一个新的 [[Vector3]] 对象来表示移动方向，其 x 和 z 分量分别由水平和垂直输入决定，y 分量设为 0。`normalized` 方法将向量标准化，使其长度为1，以确保对象在任何方向上移动时速度一致。
- 将移动方向乘以移动速度和时间增量（`Time.deltaTime`），以便使运动平滑并且不受帧率的影响。
- 最后，将计算得到的新位置赋给游戏对象的 `transform.position`，实现了对象的运动和移动。

这是一个简单的移动脚本示例，您可以根据项目的需要进行修改和扩展。
