以下是一个简单的二维旋转的示例代码，使用Unity中的C#语言实现：

```csharp
using UnityEngine;

public class RotationExample : MonoBehaviour
{
    // 旋转速度
    public float rotationSpeed = 50f;

    void Update()
    {
        // 获取当前游戏对象的旋转角度
        float currentRotation = transform.rotation.eulerAngles.z;

        // 计算新的旋转角度
        float newRotation = currentRotation + rotationSpeed * Time.deltaTime;

        // 使用新的旋转角度更新游戏对象的旋转
        transform.rotation = Quaternion.Euler(0f, 0f, newRotation);
    }
}
```

在这个示例中：

- `rotationSpeed` 定义了旋转的速度，单位是度/秒。
- `Update()` 方法每帧被调用，用于更新游戏对象的旋转。
- `transform.rotation.eulerAngles.z` 用于获取当前游戏对象的旋转角度（绕z轴的角度）。
- 计算新的旋转角度时，将当前角度加上旋转速度乘以时间增量 `Time.deltaTime`，以实现平滑的旋转效果。
- 使用 `Quaternion.Euler()` 方法创建一个旋转四元数，然后将其赋值给游戏对象的旋转属性 `transform.rotation`，从而实现旋转。

通过修改 `rotationSpeed` 可以控制旋转的速度，通过调整 `transform.rotation.eulerAngles.z` 可以改变旋转的起始角度。
