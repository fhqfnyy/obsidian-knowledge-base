以下是一个简单的示例程序，演示如何在Unity中使用刚体（Rigidbody）组件模拟物体的运动：

```csharp
using UnityEngine;

public class RigidbodySimulation : MonoBehaviour
{
    // 定义移动速度
    public float moveSpeed = 5f;

    void Update()
    {
        // 获取用户输入
        float horizontalInput = Input.GetAxis("Horizontal");
        float verticalInput = Input.GetAxis("Vertical");

        // 创建移动方向向量
        Vector3 moveDirection = new Vector3(horizontalInput, 0f, verticalInput).normalized;

        // 获取刚体组件
        Rigidbody rb = GetComponent<Rigidbody>();

        // 在固定时间间隔内更新物体位置
        rb.MovePosition(transform.position + moveDirection * moveSpeed * Time.deltaTime);
    }
}
```

在这个示例中：

- `Update()` 方法每帧都会被调用，用于获取用户输入并更新物体的位置。
- 使用 `Input.GetAxis("Horizontal")` 和 `Input.GetAxis("Vertical")` 获取水平和垂直方向上的用户输入。
- 创建一个新的 `Vector3` 对象来表示移动方向，其 x 和 z 分量分别由水平和垂直输入决定，y 分量设为 0。使用 `normalized` 方法将向量标准化，以确保对象在任何方向上移动时速度一致。
- 使用 `GetComponent<Rigidbody>()` 方法获取游戏对象上的刚体组件。
- 使用 `Rigidbody.MovePosition()` 方法在固定的时间间隔内更新游戏对象的位置，以模拟物体的运动。
