以下是一个简单的示例代码，演示如何使用固定角度旋转来对游戏对象进行旋转：

```csharp
using UnityEngine;

public class FixedAngleRotationExample : MonoBehaviour
{
    // 旋转速度
    public float rotationSpeed = 50f;

    // 目标旋转角度
    public float targetAngle = 90f;

    void Update()
    {
        // 计算每帧旋转的角度
        float angle = rotationSpeed * Time.deltaTime;

        // 如果当前旋转角度还未达到目标角度，则继续旋转
        if (transform.eulerAngles.y < targetAngle)
        {
            // 使用固定角度旋转
            transform.Rotate(Vector3.up, angle);
        }
    }
}
```

在这个示例中：

- `rotationSpeed` 定义了旋转的速度，单位是度/秒。
- `targetAngle` 定义了目标旋转的角度。
- `Update()` 方法每帧被调用，用于更新游戏对象的旋转。
- `transform.eulerAngles.y` 用于获取当前游戏对象绕 Y 轴的旋转角度。
- 如果当前旋转角度还未达到目标角度，则继续旋转。否则停止旋转。
- 使用 `transform.Rotate()` 方法来进行固定角度旋转，其中 `Vector3.up` 表示 Y 轴，`angle` 表示每帧旋转的角度。

通过修改 `rotationSpeed` 和 `targetAngle` 可以控制旋转的速度和目标角度，从而实现不同的旋转效果。
