以下是一个简单的示例代码，演示如何使用局部轴对游戏对象进行旋转，使其绕自身的局部坐标系进行旋转：

```csharp
using UnityEngine;

public class LocalAxisRotationExample : MonoBehaviour
{
    // 旋转速度
    public float rotationSpeed = 50f;

    void Update()
    {
        // 获取当前游戏对象的局部旋转
        Vector3 localRotation = transform.localEulerAngles;

        // 计算旋转角度
        float angle = rotationSpeed * Time.deltaTime;

        // 使用局部轴来旋转，这里以 Y 轴为例
        transform.Rotate(Vector3.up, angle);
    }
}
```

在这个示例中：

- `rotationSpeed` 定义了旋转的速度，单位是度/秒。
- `Update()` 方法每帧被调用，用于更新游戏对象的旋转。
- `transform.localEulerAngles` 用于获取当前游戏对象的局部旋转角度。
- 使用 `transform.Rotate()` 方法来绕局部轴进行旋转，其中 `Vector3.up` 表示以 Y 轴为旋转轴，`angle` 表示每帧旋转的角度。

通过修改 `rotationSpeed` 可以控制旋转的速度，从而实现不同的旋转效果。
