以下是一个简单的示例程序，演示如何在Unity中使用刚体（Rigidbody）组件模拟物体受到重力影响：

```csharp
using UnityEngine;

public class GravitySimulation : MonoBehaviour
{
    // 定义重力加速度
    public float gravity = 9.81f;

    // 获取刚体组件
    private Rigidbody rb;

    void Start()
    {
        // 获取游戏对象上的刚体组件
        rb = GetComponent<Rigidbody>();
    }

    void Update()
    {
        // 计算下落速度
        float fallSpeed = gravity * rb.mass * Time.deltaTime;

        // 应用重力效果
        rb.AddForce(Vector3.down * fallSpeed, ForceMode.Acceleration);
    }
}
```

在这个示例中：

- 在 `Start()` 方法中获取游戏对象上的刚体组件。
- 在 `Update()` 方法中计算物体下落的速度，使用公式 `fallSpeed = gravity * rb.mass * Time.deltaTime` 计算下落速度。其中，`gravity` 是重力加速度，`rb.mass` 是物体的质量，`Time.deltaTime` 是上一帧到当前帧的时间间隔。
- 使用 `rb.AddForce()` 方法应用重力效果，传入一个向下的力向量 `Vector3.down * fallSpeed`。这个力向量的大小等于物体受到的重力加速度乘以时间间隔，方向向下。`ForceMode.Acceleration` 指定了力的模式为加速度，这样会根据物体的质量产生适当的加速度。
