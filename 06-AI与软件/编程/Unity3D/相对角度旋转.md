以下是一个简单的示例代码，演示如何使用相对角度旋转来对游戏对象进行旋转：

```csharp
using UnityEngine;

public class RelativeAngleRotationExample : MonoBehaviour
{
    // 旋转速度
    public float rotationSpeed = 50f;

    // 相对旋转角度
    public float relativeAngle = 90f;

    void Update()
    {
        // 计算每帧旋转的角度
        float angle = rotationSpeed * Time.deltaTime;

        // 使用相对角度旋转
        transform.Rotate(Vector3.up, angle, Space.Self);

        // 检查是否达到目标旋转角度，如果达到则停止旋转
        if (Mathf.Abs(transform.localEulerAngles.y) >= relativeAngle)
        {
            enabled = false; // 停止此脚本的执行
        }
    }
}
```

在这个示例中：

- `rotationSpeed` 定义了旋转的速度，单位是度/秒。
- `relativeAngle` 定义了相对旋转的角度。
- `Update()` 方法每帧被调用，用于更新游戏对象的旋转。
- `transform.Rotate()` 方法用于相对角度旋转，其中 `Vector3.up` 表示 Y 轴，`angle` 表示每帧旋转的角度，`Space.Self` 表示相对于物体本身的局部坐标系进行旋转。
- 使用 `transform.localEulerAngles.y` 获取当前游戏对象相对于其自身局部坐标系的 Y 轴旋转角度。
- 如果达到目标相对旋转角度，则停止旋转，通过禁用脚本的执行来实现。

通过修改 `rotationSpeed` 和 `relativeAngle` 可以控制旋转的速度和相对角度，从而实现不同的旋转效果。
