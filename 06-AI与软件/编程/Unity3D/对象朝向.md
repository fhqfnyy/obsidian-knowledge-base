要让一个对象朝向另一个对象，你可以使用 `Transform.LookAt()` 方法。这个方法会使得一个对象的 Z 轴朝向目标对象，从而朝向它。下面是一个简单的示例代码，展示如何让一个对象朝向另一个对象：

```csharp
using UnityEngine;

public class LookAtExample : MonoBehaviour
{
    // 目标对象
    public Transform target;

    void Update()
    {
        // 将当前对象朝向目标对象
        transform.LookAt(target);
    }
}
```

在这个示例中：

- `target` 是要朝向的目标对象的 `Transform` 组件。
- `Update()` 方法每帧被调用，用于更新当前对象的朝向。
- `transform.LookAt(target)` 方法会使得当前对象朝向目标对象，使得当前对象的 Z 轴指向目标对象。

你可以将这个脚本挂载到需要朝向目标的对象上，并将目标对象指定为 `target`。然后，当游戏运行时，当前对象将会始终朝向目标对象。

需要注意的是，`LookAt()` 方法会使得对象的 Z 轴指向目标对象，但它不会改变对象的位置。如果你想让对象既朝向目标对象又移动向它，你需要在处理对象的位置上进行额外的操作。
