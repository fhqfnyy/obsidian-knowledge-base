以下是一个简单的示例代码，演示如何使用目标角度旋转来对游戏对象进行旋转：

```csharp
using UnityEngine;

public class TargetAngleRotationExample : MonoBehaviour
{
    // 旋转速度
    public float rotationSpeed = 50f;

    // 目标旋转角度
    public float targetAngle = 90f;

    void Update()
    {
        // 获取当前游戏对象的旋转角度
        float currentRotation = transform.rotation.eulerAngles.y;

        // 计算与目标旋转角度的差值
        float angleDifference = Mathf.DeltaAngle(currentRotation, targetAngle);

        // 如果与目标旋转角度的差值大于旋转速度，继续旋转
        if (Mathf.Abs(angleDifference) > rotationSpeed * Time.deltaTime)
        {
            // 计算每帧旋转的角度
            float rotationAngle = Mathf.Sign(angleDifference) * rotationSpeed * Time.deltaTime;

            // 使用目标角度旋转
            transform.Rotate(Vector3.up, rotationAngle);
        }
    }
}
```

在这个示例中：

- `rotationSpeed` 定义了旋转的速度，单位是度/秒。
- `targetAngle` 定义了目标旋转的角度。
- `Update()` 方法每帧被调用，用于更新游戏对象的旋转。
- 使用 `transform.rotation.eulerAngles.y` 获取当前游戏对象的旋转角度。
- 使用 `Mathf.DeltaAngle()` 计算当前旋转角度与目标旋转角度的差值。
- 如果与目标旋转角度的差值大于旋转速度乘以时间增量 `Time.deltaTime`，则继续旋转，否则停止旋转。
- 使用 `transform.Rotate()` 方法进行旋转，旋转角度为 `rotationSpeed * Time.deltaTime`，方向由当前旋转角度与目标旋转角度的差值决定。

通过修改 `rotationSpeed` 和 `targetAngle` 可以控制旋转的速度和目标角度，从而实现不同的旋转效果。
