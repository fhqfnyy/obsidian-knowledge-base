标签 (Label) 控件是 WinForms 中常用的控件之一，用于在用户界面中显示静态文本信息。以下是关于标签控件的一些详细信息：

1. **显示静态文本**：
   - 标签控件通常用于显示静态文本信息，例如说明性文字、标题、标签等。与文本框不同，标签控件的内容通常是只读的，用户无法对其进行编辑或修改。

2. **属性**：
   - 标签控件具有多个属性，用于自定义其外观和行为。常用属性包括 Text、ForeColor、BackColor、Font 等。
   - Text 属性用于设置标签中显示的文本内容。
   - ForeColor 属性用于设置文本的前景色，即文本的颜色。
   - BackColor 属性用于设置标签的背景色。
   - Font 属性用于设置文本的字体样式，包括字体名称、大小、样式等。

3. **自动换行**：
   - 标签控件默认情况下不支持自动换行，即当文本超出标签控件的可见范围时，文本将被截断显示。但可以通过设置 AutoSize 和 AutoEllipsis 属性来实现自动换行或省略号显示。

4. **使用方法**：
   - 在设计工具中，可以通过拖放的方式将标签控件添加到窗体上，并通过属性窗口设置其属性。
   - 开发者还可以通过代码动态创建标签控件，并将其添加到窗体上。例如：
     ```csharp
     Label label = new Label();
     label.Text = "Welcome to My Application";
     label.Location = new Point(50, 50);
     label.ForeColor = Color.Blue;
     label.Font = new Font("Arial", 12, FontStyle.Bold);
     this.Controls.Add(label);
     ```

5. **交互性**：
   - 标签控件通常是静态的，用户不能与其交互。但是，开发者可以将标签控件与其他控件结合使用，例如将标签用作其他控件的标识或说明。

标签控件是构建用户界面中常见的显示元素之一，它可以用于显示说明性文字、提示信息、标题等，帮助用户理解界面的结构和功能。
