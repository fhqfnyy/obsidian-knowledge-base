C++11、C++14、C++17 和 C++20 是C++语言的重要版本，每个版本都引入了许多新特性，提高了语言的表达力、性能和安全性。以下是这些版本的一些主要新特性及其示例。

### C++11 新特性

#### 1. 自动类型推导 (`auto`)

自动类型推导让编译器根据初始化表达式自动推断变量的类型。

```cpp
#include <iostream>
#include <vector>

int main() {
    auto x = 5;        // int
    auto y = 3.14;     // double
    auto z = "hello";  // const char*
    
    std::vector<int> vec = {1, 2, 3, 4};
    for (auto i : vec) {
        std::cout << i << " "; // 输出: 1 2 3 4
    }
    std::cout << std::endl;
    return 0;
}
```

#### 2. 范围for循环

简化对容器和数组的遍历。

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    for (int i : vec) {
        std::cout << i << " "; // 输出: 1 2 3 4 5
    }
    std::cout << std::endl;
    return 0;
}
```

#### 3. Lambda 表达式

引入匿名函数，使得内联定义和调用函数更加方便。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    std::for_each(vec.begin(), vec.end(), [](int n) { std::cout << n << " "; });
    // 输出: 1 2 3 4 5
    std::cout << std::endl;
    return 0;
}
```

#### 4. 智能指针

引入了 `std::unique_ptr` 和 `std::shared_ptr`，自动管理动态内存，防止内存泄漏。

```cpp
#include <iostream>
#include <memory>

int main() {
    std::unique_ptr<int> ptr1 = std::make_unique<int>(10);
    std::cout << *ptr1 << std::endl; // 输出: 10

    std::shared_ptr<int> ptr2 = std::make_shared<int>(20);
    std::shared_ptr<int> ptr3 = ptr2; // 共享所有权
    std::cout << *ptr3 << std::endl; // 输出: 20
    return 0;
}
```

#### 5. `nullptr`

引入了新的空指针常量 `nullptr`，取代了旧的 `NULL` 宏。

```cpp
#include <iostream>

void foo(int* ptr) {
    if (ptr == nullptr) {
        std::cout << "Pointer is null" << std::endl;
    } else {
        std::cout << "Pointer is not null" << std::endl;
    }
}

int main() {
    int* p = nullptr;
    foo(p); // 输出: Pointer is null
    return 0;
}
```

#### 6. `std::thread`

引入多线程支持，使并发编程更加方便。

```cpp
#include <iostream>
#include <thread>

void print_message(const std::string& message) {
    std::cout << message << std::endl;
}

int main() {
    std::thread t(print_message, "Hello from thread");
    t.join(); // 等待线程完成
    return 0;
}
```

### C++14 新特性

#### 1. 二进制字面量

可以使用 `0b` 或 `0B` 前缀定义二进制字面量。

```cpp
#include <iostream>

int main() {
    int binary = 0b1010; // 二进制数1010，即10
    std::cout << binary << std::endl; // 输出: 10
    return 0;
}
```

#### 2. 泛型 Lambda

Lambda 表达式可以使用 `auto` 进行参数类型推导。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    auto print = [](auto x) { std::cout << x << " "; };

    std::for_each(vec.begin(), vec.end(), print); // 输出: 1 2 3 4 5
    std::cout << std::endl;
    return 0;
}
```

#### 3. `std::make_unique`

为 `std::unique_ptr` 提供了更安全和简洁的创建方式。

```cpp
#include <iostream>
#include <memory>

int main() {
    auto ptr = std::make_unique<int>(42);
    std::cout << *ptr << std::endl; // 输出: 42
    return 0;
}
```

### C++17 新特性

#### 1. `std::optional`

表示一个可能为空的值，替代常见的返回空指针或使用布尔标志的方法。

```cpp
#include <iostream>
#include <optional>

std::optional<int> find_even(int num) {
    if (num % 2 == 0) {
        return num;
    } else {
        return std::nullopt;
    }
}

int main() {
    auto result = find_even(4);
    if (result) {
        std::cout << "Even number: " << *result << std::endl; // 输出: Even number: 4
    } else {
        std::cout << "Number is not even" << std::endl;
    }
    return 0;
}
```

#### 2. 结构化绑定

使得可以将结构或类的成员变量解构为独立的变量。

```cpp
#include <iostream>
#include <tuple>

int main() {
    std::tuple<int, double, std::string> t(1, 2.3, "hello");

    auto [i, d, s] = t;
    std::cout << "i: " << i << ", d: " << d << ", s: " << s << std::endl;
    // 输出: i: 1, d: 2.3, s: hello

    return 0;
}
```

#### 3. `if` 初始化语句

可以在 `if` 和 `switch` 语句中初始化变量。

```cpp
#include <iostream>

int main() {
    if (int x = 42; x > 40) {
        std::cout << "x is greater than 40" << std::endl; // 输出: x is greater than 40
    }
    return 0;
}
```

#### 4. `std::any`

可以存储任意类型的值，并提供类型安全的访问。

```cpp
#include <iostream>
#include <any>

int main() {
    std::any a = 42;
    a = std::string("hello");

    try {
        std::cout << std::any_cast<std::string>(a) << std::endl; // 输出: hello
    } catch (const std::bad_any_cast& e) {
        std::cout << e.what() << std::endl;
    }
    return 0;
}
```

#### 5. `std::filesystem`

提供跨平台的文件系统操作功能。

```cpp
#include <iostream>
#include <filesystem>

namespace fs = std::filesystem;

int main() {
    fs::create_directory("example");
    std::cout << "Created directory 'example'" << std::endl;
    fs::remove("example");
    std::cout << "Removed directory 'example'" << std::endl;
    return 0;
}
```

### C++20 新特性

#### 1. 协程

协程是可以在执行过程中暂停和恢复的函数。

```cpp
#include <iostream>
#include <coroutine>

struct Coroutine {
    struct promise_type {
        Coroutine get_return_object() { return {}; }
        std::suspend_always initial_suspend() { return {}; }
        std::suspend_always final_suspend() noexcept { return {}; }
        void return_void() {}
        void unhandled_exception() {}
    };
};

Coroutine my_coroutine() {
    std::cout << "Hello from coroutine" << std::endl;
    co_return;
}

int main() {
    my_coroutine();
    return 0;
}
```

#### 2. 三方比较运算符（太空船运算符 `<=>`）

简化比较操作，自动生成所有比较运算符。

```cpp
#include <iostream>

struct Point {
    int x, y;
    auto operator<=>(const Point&) const = default;
};

int main() {
    Point p1{1, 2}, p2{1, 3};
    if (p1 < p2) {
        std::cout << "p1 is less than p2" << std::endl; // 输出: p1 is less than p2
    }
    return 0;
}
```

#### 3. 概念（Concepts）

概念用于约束模板的类型参数。

```cpp


#include <iostream>
#include <concepts>

template<typename T>
concept Integral = std::is_integral_v<T>;

template<Integral T>
T add(T a, T b) {
    return a + b;
}

int main() {
    std::cout << add(1, 2) << std::endl; // 输出: 3
    // std::cout << add(1.0, 2.0) << std::endl; // 错误: double 不是 Integral
    return 0;
}
```

#### 4. 范围库（Ranges）

提供一组用于操作范围（序列）的算法和视图。

```cpp
#include <iostream>
#include <ranges>
#include <vector>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5, 6};

    auto even = [](int i) { return i % 2 == 0; };
    auto squared = [](int i) { return i * i; };

    for (int i : vec | std::views::filter(even) | std::views::transform(squared)) {
        std::cout << i << " "; // 输出: 4 16 36
    }
    std::cout << std::endl;

    return 0;
}
```

以上是C++11、C++14、C++17和C++20的一些主要新特性及其实例。这些特性大大增强了C++语言的表达力和灵活性，使得编写高效、安全和可维护的代码变得更加容易。
