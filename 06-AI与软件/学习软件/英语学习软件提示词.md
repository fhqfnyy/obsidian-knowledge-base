# 一、系统级总提示词（核心）

👉 用于让AI一次性生成完整项目架构

```
你是一名资深全栈工程师，请开发一个“基于AI的英语学习Web应用”，要求如下：

【技术栈要求】
前端：React + Vite + TypeScript + TailwindCSS + Zustand
后端：Node.js + Express（或NestJS）
数据库：PostgreSQL（或MongoDB）
AI能力：调用OpenAI API或本地大模型
OCR识别：Tesseract.js 或 PaddleOCR（Web版）

【核心功能模块】
1. 图片识别单词（OCR）
- 支持上传图片或调用摄像头拍照
- 自动识别图片中的英文单词
- 提取词汇列表并去重

2. 单词管理系统
- 支持手动输入单词（单个 / 批量）
- 支持创建“词汇分组”（如：CET4 / 技术英语 / 日常）
- 单词可加入多个分组
- 支持标签系统（动词、名词、专业词等）

3. AI词汇解析
针对每个单词自动生成：
- 中文释义（多个义项）
- 英文音标（英式 / 美式）
- 发音（TTS）
- 示例句（英文）
- 示例句翻译（中文）
- 单词配图（调用图片API）
- 词根词缀解析（可选）

4. 闪卡学习系统（Flashcards）
支持多种模式：
- 英文 → 选中文
- 听发音 → 选中文
- 中文 → 拼写英文
- 英文 → 回忆释义

5. 艾宾浩斯记忆算法
- 自动安排复习时间
- 单词状态：新词 / 学习中 / 熟练 / 遗忘
- 根据用户表现动态调整复习频率

6. AI造句练习
- 用户根据单词造句
- AI判断：
  - 语法正确性
  - 是否自然
  - 是否符合语境
- 给出优化建议

7. 学习统计系统
- 每日学习量
- 掌握词汇数
- 记忆曲线
- 正确率统计
- 学习时长

【UI设计要求】
- 简洁现代（类似Notion + Duolingo）
- 深色 / 浅色模式
- 支持移动端响应式
- 关键页面：
  - 首页仪表盘
  - 单词列表页
  - 学习页（闪卡）
  - OCR识别页
  - 统计分析页

【输出内容】
请生成：
1. 项目目录结构
2. 数据库设计（ER图或SQL）
3. 核心API设计
4. 前端页面结构
5. 关键代码示例（OCR / AI / 闪卡）
6. 艾宾浩斯算法实现逻辑
```

# 五、模型路由策略（非常关键🔥）

```id="r9c2lh"

规则：
- 单词解析 → 使用低成本模型（Ollama / Minimax）
- AI造句批改 → 使用高精度模型（OpenAI / NVIDIA）
- OCR纠错 → 使用快速模型

实现：
function selectModel(taskType) {
  switch(taskType) {
    case "word_explain":
      return { provider: "ollama", model: "llama3" }
    case "sentence_check":
      return { provider: "openai", model: "gpt-4" }
  }
}
```
