# 一、安卓版总提示词（核心🔥）

👉 可直接用于 Cursor / ChatGPT / Claude 生成完整APP

```id="android_main_prompt"
你是一名资深移动端工程师，请开发一个“基于AI的英语学习Android应用”。

【技术选型（优先推荐）】
方案1：Flutter（推荐，跨平台）
方案2：React Native
方案3：原生Kotlin（如需高性能）

【核心功能】

1. OCR识别（重点）
- 支持拍照识别（调用摄像头）
- 支持从相册选择图片
- 使用：
  - Google ML Kit OCR（优先）
  - 或 Tesseract
- 自动提取英文单词
- 去重 + 清洗数据

2. 单词管理
- 手动输入（单个 / 批量）
- 创建词汇分组（标签）
- 支持搜索 / 分类 / 收藏
- 本地数据库存储（SQLite / Room / Hive）

3. AI词汇解析（多模型支持🔥）
- 支持供应商：
  - Ollama（本地）
  - OpenAI
  - Minimax
  - 火山引擎
  - NVIDIA

- 自动生成：
  - 中文解释（多义）
  - 音标（美式 / 英式）
  - 发音（TTS）
  - 例句 + 翻译
  - 图片

4. 闪卡学习系统
模式：
- 英文 → 中文
- 听音 → 选义
- 中文 → 拼写
- 英文 → 回忆

支持：
- 滑动卡片（类似Anki / Quizlet）
- 动画效果

5. 艾宾浩斯记忆算法
- 自动安排复习
- 单词熟练度系统
- 间隔复习（1/3/7/15/30天）

6. AI造句练习
- 用户输入句子
- AI批改：
  - 语法
  - 自然度
  - 改进建议

7. 学习统计
- 学习时长
- 掌握词汇量
- 正确率
- 曲线图

8. AI模型选择（核心🔥）
- 设置页面选择：
  - provider
  - model
  - API Key
- 支持多模型切换
- 支持fallback机制

【UI设计】
- 风格：Duolingo + Notion
- 深色模式支持
- 页面：
  - 首页（学习进度）
  - OCR识别页
  - 单词本
  - 学习页（闪卡）
  - AI练习页
  - 设置页（AI模型）

【输出要求】
1. 项目结构
2. 页面结构
3. 状态管理方案
4. 核心代码示例
5. API调用封装
```

  - nvidia

  model,
  prompt
})
