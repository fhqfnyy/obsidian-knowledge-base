# 一、核心改造思路（必须先纠正）

你的当前逻辑：

```text
学习 = 新词输入
复习 = 从词库随机抽
```

👉 这是错的

---

✅ 正确逻辑应该是：

```text
学习系统 = 新词学习 + 错词强化 + 记忆调度 + 复习队列
```

---

# 二、核心模型（4个池子模型🔥）

你必须引入 **“词汇状态池”**

---

## 🧠 1️⃣ 四大池子结构

```text
[新词池] → [学习中] → [待复习] → [长期记忆]
              ↓
           [错词池]
```

---

## 📌 每个池子的作用

|池子|作用|
|---|---|
|新词池|每天20个入口|
|学习中|当前正在掌握|
|错词池|强制重复|
|待复习|已学过但未稳固|
|长期记忆|已掌握|

---

# 三、学习流程（你现在最缺的）

---

## 🧩 Step 1：每日任务分配

👉 每天不是只学20个！

```text
每日任务 = 新词（20） + 复习词（动态）
```

建议：

```text
新词：20
复习：30~100（根据积压）
```

---

## 🧩 Step 2：新词学习逻辑（关键）

```python
for word in 今日20个新词:
    while True:
        result = 用户答题(word)

        if result == 正确:
            标记为“初步掌握”
            加入待复习池
            break
        else:
            加入错词池
```

---

## 🧩 Step 3：错词强化机制（你现在缺的🔥）

👉 错词不能“混入”，必须**锁死重复**

```python
while 错词池不为空:
    word = 取一个错词

    result = 用户答题(word)

    if result == 正确:
        连续正确 += 1
    else:
        连续正确 = 0

    if 连续正确 >= 2:
        移出错词池
        加入待复习池
```

👉 核心：

```text
错词必须连续答对2~3次才放行
```

# 四、复习系统（彻底修复你的问题🔥）

你现在最大的问题：

> ❌ 复习 = 随机抽词库  
> ✅ 正确 = 复习 = “到期任务”

---

## 🧠 每个词必须有“记忆参数”

```json
{
  "word": "abandon",
  "status": "review",
  "interval": 1,
  "ease": 2.5,
  "next_review": "2026-03-28",
  "wrong_count": 2,
  "streak": 1
}
```

---

## 📅 复习调度核心

```python
if 今天 >= next_review:
    加入复习队列
```

---

## 🧩 复习执行逻辑

```python
for word in 复习队列:

    result = 用户答题(word)

    if result == 正确:
        interval *= 2
        ease += 0.1
        streak += 1
    else:
        interval = 1
        ease -= 0.2
        streak = 0
        加入错词池

    next_review = 今天 + interval
```

---

👉 关键点：

```text
复习不是“随机”，是“到期”
```
