# 文档处理技能

## 概述

这些Python库用于处理各种文档格式，是构建AI应用和RAG系统的核心技术。

## 库功能说明

| 库 | 功能 |
|---|------|
| **docling** | 面向AI的文档解析，支持PDF/Word/Excel等转为Markdown/JSON |
| **pdfplumber** | PDF文本和表格提取 |
| **pymupdf** | 高性能PDF处理（提取、修改、渲染） |
| **pdfminer.six** | PDF文本和结构解析 |
| **unstructured** | 通用文档处理，支持多种格式自动分区 |
| **natural-pdf** | 友好的PDF处理，保留布局信息 |
| **doc2mark** | 将任意文档转换为Markdown格式 |

## 使用示例

### docling - 文档转AI可用格式
```python
from docling.document_converter import DocumentConverter

converter = DocumentConverter()
doc = converter.convert("document.pdf")
print(doc.document.to_markdown())
```

### pdfplumber - PDF表格提取
```python
import pdfplumber

with pdfplumber.open("file.pdf") as pdf:
    text = pdf.pages[0].extract_text()
    tables = pdf.pages[0].extract_tables()
```

### unstructured - 通用文档分区
```python
from unstructured.partition.auto import partition

elements = partition("document.pdf")
for el in elements:
    print(el)
```
