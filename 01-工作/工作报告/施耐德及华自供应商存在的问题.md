# 施耐德及华自供应商存在的问题

## 自控供应商华自方面存在的问题：

1. **材料进场时间较晚，影响施工进度**。
2. **图纸深化设计不完善，施工图纸缺失**。
3. **施工计划缺失，导致工程施工时间表无法准确制定**。
4. **由于以上原因导致施工进度相对缓慢**。

虽然华自因为以上原因进度相对缓慢，但对方的工作施工质量较好，软件的开发速度和开发质量都值得肯定；到场的工作人与我方工作人员配合默契，工作成绩得到甲方认可。

## 中压柜及软启动存在的问题

1. **二期水泵房2中压柜六氟化硫断路器漏气**。服务工程师到场未能解决，目前具体解决时间未知。
2. **一期水源厂4号软启动和水泵房2号软启动出现故障**。向施耐德询问购买配件，迟迟无法得到有效回复。经过两个月的催促，终于得到回复，但配件价格高的惊人：1块控制板和3个电抗器报价35万人民币，货期还要10个月。这一价格足够在国内购买一台相同功率的高压变频器。
3. **二期定制的6台软启动中有3台缺少电压检测PT**。向其询问原因时，回复说因为缺少配件，测试时借用其他设备上的PT，测试完成后归还。发货时并没有告知我方缺失配件情况；到目前为止也未能确定缺失配件的具体到货时间。
4. 基于以上原因，建议**三期软启动一定要更换其他品牌**。现有存在问题的软启动如果能争取到甲方的认可，也要换成其他品牌。如果继续采用这个品牌，无论采购成本还是故障修复成本都极其高昂，并且成品和配件的供货周期都极其漫长。
