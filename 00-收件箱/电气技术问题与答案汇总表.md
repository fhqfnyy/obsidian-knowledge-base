## **电气技术问题与答案汇总表**

|序号|问题|答案摘要|
|---|---|---|
|1|**高压开关柜的五防是什么？**|① 防止误分、误合断路器；② 防止带负荷分合隔离开关；③ 防止带电合接地开关；④ 防止接地状态下送电；⑤ 防止误入带电间隔。主要依靠机械、电气及程序闭锁实现。|
|2|**高压电缆的结构有哪些？**|由内到外主要包括：导体、导体半导电屏蔽层、XLPE主绝缘层、绝缘半导电屏蔽层、金属屏蔽层及外部保护结构。根据电缆类型，还包括填充层、内护套、铠装层和外护套。|
|3|**高压电缆半导电层有什么作用？**|内半导电层平滑导体表面的电场边界；外半导电层配合金属屏蔽层形成稳定的外部电场边界。主要作用是均匀电场、减少局部电场集中和局部放电。制作终端时必须正确处理屏蔽层断口及应力控制。|
|4|**发电机并联系统需要哪些组成部分？**|主要包括发电机组、调速器、AVR、自动同期装置、有功负荷分配、无功负荷分配、并机断路器、母线及保护监控系统。多个功能可集成在综合并机控制器中。|
|5|**变压器和发电机的短路电流曲线有什么区别？**|变压器接强电网时，短路电流交流对称分量通常基本稳定；同步发电机短路电流经历次暂态、暂态及持续阶段，电流通常先快速衰减，后续取决于励磁系统。孤网系统尤其需要考虑末端故障电流衰减导致保护拒动。|
|6|**短路电流曲线与额定电流有什么关系？**|额定电流通常作为1.0In基准线。短路电流以额定电流倍数表示。变压器短路电流近似为 \(I_N/u_k\)；发电机初始对称短路电流近似为 \(I_N/X_d''\)。|
|7|**离心泵和恒转矩负载的启动特征有什么区别？**|离心泵理想负载转矩近似与转速平方成正比；恒转矩负载的转矩基本不随转速变化。相同电动机直接启动时，初始电流主要取决于堵转阻抗，通常约为5～8In；负载特性主要影响加速过程和大电流持续时间。|
|8|**变频启动0～50Hz、加速10秒时，两类负载的电流曲线有什么区别？**|理想离心泵的负载转矩随转速增加而增大，电机电流通常逐步上升；恒转矩负载从低速开始就需要较大转矩，电流可能在加速阶段维持较高水平。实际电流还取决于励磁、惯量、加速转矩及控制方式。|
|9|**变频器矢量控制与V/f控制有什么区别？**|V/f控制按频率调整电压，结构简单，适用于一般水泵和风机；矢量控制通过电机模型分别控制磁通和转矩电流，低速转矩和动态响应更好。矢量控制不意味着启动电流一定更小。|
|10|**变压器并联运行的必要条件有哪些？**|变比匹配、接线组别一致、相序及对应相位一致、短路阻抗接近、阻抗角接近。不同容量可以并联，但应校核负荷分配、环流、保护和设备容量。|
|11|**发电机并联运行的必要条件有哪些？**|同期合闸须满足电压幅值接近、频率接近、相序一致及相位角接近零。稳定并联运行还需要有功、无功负荷分配系统及必要的保护和联锁。|
|12|**不同容量变压器如何分配负荷？**|主要由变压器容量和短路阻抗决定。变比一致且阻抗角接近时，负荷近似按照 \(S_N/u_k\) 的比例分配。短路阻抗百分比相同时，基本按额定容量比例分配。|

## **关键公式速查表**

| 技术项目           | 计算公式                                                            | 说明                     |
| -------------- | --------------------------------------------------------------- | ---------------------- |
| 三相额定电流         | \(I_N=\dfrac{S_N}{\sqrt3 U_N}\)                                 | 容量采用VA，电压采用V           |
| 变压器初始短路电流近似值   | \(I_k\approx\dfrac{I_N}{u_k}\)                                  | \(u_k\) 为标幺值，假设上级电源足够强 |
| 发电机初始对称短路电流近似值 | \(I_k''\approx\dfrac{I_N}{X_d''}\)                              | \(X_d''\) 为次暂态电抗标幺值    |
| 离心泵理想负载转矩      | \(T_L=T_N(n/n_N)^2\)                                            | 适用于相似工况下的简化分析          |
| 离心泵理想轴功率       | \(P_L=P_N(n/n_N)^3\)                                            | 不适用于所有存在静扬程的实际工况       |
| 恒转矩负载功率        | \(P_L=T_L\omega\)                                               | 功率与转速近似成正比             |
| 电机加速转矩         | \(T_a=T_e-T_L\)                                                 | 加速转矩等于电磁转矩减去负载转矩       |
| V/f控制          | \(U/f\approx常数\)                                                | 基频以下维持近似恒定磁通           |
| 变压器并联负荷比例      | \(\dfrac{S_1}{S_2}\approx\dfrac{S_{N1}/u_{k1}}{S_{N2}/u_{k2}}\) | 变比相同、阻抗角相近时适用          |
| 变频器线性加速频率      | \(f(t)=50t/10\)                                                 | 0～10秒线性加速到50Hz         |
