## 一、每张卡片的处理任务

对每张卡片：

1. 读取法语例句。
    
2. 根据该例句生成简洁、易懂的中文解析。
    
3. 将解析结果写入【助记符】字段。
    
4. 如果【助记符】已有内容，直接覆盖原内容。
    
5. 不修改其他任何字段。
    

---

## 二、解析要求

每个例句按照以下思路解析：

1. 先给出整句话自然、符合中文习惯的意思。
    
2. 再按照有意义的短语、表达或结构拆开解释。
    
3. 不要机械逐词翻译。
    
4. 找出这句话中最值得学习和记忆的 1～2 个内容，例如：
    
    - 常用表达
        
    - 固定搭配
        
    - 动词结构
        
    - 常见句型
        
    - 重要介词用法
        
    - 动词变位
        
    - 被动语态
        
    - 常见时态
        
5. 重点解释这些真正影响句子理解、并且值得以后直接套用的内容。
    
6. 如果出现动词变位，只解释和当前句子直接相关的原形、变位和含义。
    
7. 如果出现被动语态，可以简单说明：
    
    - 原形结构
        
    - 当前句子的构成
        
    - 必要时给出对应主动句
        
8. 如果出现特殊介词，例如：
    
    - à
        
    - de
        
    - par
        
    - pour
        
    - chez
        
    - en
        
    - dans  
        等，只解释它在当前句子中的实际作用。
        
9. 必要时可以补充：
    
    - 主动句 / 被动句转换
        
    - 类似表达
        
    - 1～2 个简单例句
        
10. 不要重点分析：
    

- 名词阴阳性
    
- 冠词
    
- 词性
    
- 复杂语法术语  
    除非这些内容确实影响当前句子的理解。
    

11. 不要为了讲语法而讲语法。
    
12. 目标是让学习者：
    

- 看懂这句话
    
- 理解为什么这样表达
    
- 记住可以直接使用的法语表达
    

13. 使用中文解释。
    
14. 关键法语词汇、短语和句型必须保留法语原文。
    
15. 简单句简短解释即可。
    
16. 复杂句、重要固定表达或重要语法结构可以适当展开。

## 四、推荐输出结构

例如原句：

Le voleur a été arrêté par la police.

推荐写入【助记符】：

<p><b>Le voleur a été arrêté par la police.</b><br> <span class="cn">小偷被警察逮捕了。</span></p>

<p>可以这样拆开理解：</p>

<ul> <li><b>Le voleur</b> = 小偷</li> <li><b>a été arrêté</b> = 被逮捕了</li> <li><b>par la police</b> = 被警察 / 由警方</li> </ul>

<p>这里最值得注意的是 <span class="target-word">a été arrêté</span>。</p>

<p>它是法语的被动语态：</p>

<p><b>être + 过去分词</b></p>

<ul> <li><b>a été</b> = être 的复合过去时</li> <li><b>arrêté</b> = arrêter 的过去分词</li> </ul>

<p>所以：</p>

<p><b>a été arrêté</b> = 被逮捕了</p>

<p><b>对应主动句：</b></p>

<blockquote> La police a arrêté le voleur.<br> <span class="cn">警察逮捕了小偷。</span> </blockquote>

<p><b>被动句：</b></p>

<blockquote> Le voleur a été arrêté par la police.<br> <span class="cn">小偷被警察逮捕了。</span> </blockquote>

<p>这里的 <b>par</b> 类似英语里的 <b>by</b>。</p>

<p>可以直接记住：</p>

<p><span class="target-word">A + être + 过去分词 + par + B</span><br> <span class="cn">= A 被 B……</span></p>

## 五、简单句不要强行展开

如果句子本身很简单，例如：

Tu es français ?

不要为了套模板写得很长。

可以写成：

<p><b>Tu es français ?</b><br> <span class="cn">你是法国人吗？</span></p>

<ul> <li><b>Tu es</b> = 你是</li> <li><b>français</b> = 法国人 / 法国的</li> </ul>

<p>这里重点记住 <span class="target-word">Tu es + 身份 / 职业 / 国籍 ?</span>，表示“你是……吗？”</p>

<blockquote> Tu es étudiant ?<br> <span class="cn">你是学生吗？</span> </blockquote>

到这里即可，不要继续增加没有必要的语法分析。

## 六、动词变位的处理方式

如果句子中出现重要动词变位，应简单说明原形和当前形式。

例如：

Je veux partir.

可以写：

<p><b>Je veux partir.</b><br> <span class="cn">我想离开。</span></p>

<ul> <li><b>Je veux</b> = 我想 / 我要</li> <li><b>partir</b> = 离开</li> </ul>

<p>重点是 <span class="target-word">vouloir + 动词原形</span>，表示“想要做某事”。</p>

<p><b>veux</b> 是 <b>vouloir</b> 在 <b>je</b> 后面的变位。</p>

<blockquote> Je veux apprendre le français.<br> <span class="cn">我想学习法语。</span> </blockquote>

不需要把 vouloir 的全部人称变位都列出来，除非当前句子的理解确实需要。

---

## 七、固定搭配的处理方式

如果句子中有很实用的固定表达，应优先解释。

例如：

J'ai besoin de repos.

可以写：

<p><b>J'ai besoin de repos.</b><br> <span class="cn">我需要休息。</span></p>

<ul> <li><b>J'ai besoin de</b> = 我需要……</li> <li><b>repos</b> = 休息</li> </ul>

<p>这里最值得记住的是 <span class="target-word">avoir besoin de + 名词 / 动词原形</span>。</p>

<p>表示：</p>

<p><b>需要……</b></p>

<blockquote> J'ai besoin d'aide.<br> <span class="cn">我需要帮助。</span><br><br>

J'ai besoin de dormir.<br>  
<span class="cn">我需要睡觉。</span>

</blockquote>
