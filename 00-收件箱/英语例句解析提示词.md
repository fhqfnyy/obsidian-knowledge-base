任务要求：

读取每张卡片的【例句展示】字段，对例句进行简洁解析，并将结果写入对应卡片的【助记符】字段。

## 分批处理规则

1. **每 200 个词汇/卡片作为一组进行处理。**
    
2. 先完成第 1 组 200 个，再进行第 2 组。
    
3. 必须当前组全部处理完成后，才能进入下一组。
    
4. 不要同时处理多个组。
    
5. 如果最后一组不足 200 个，则处理剩余全部卡片。
    
6. 每完成一组后，简单汇报：
    
    - 当前是第几组
        
    - 本组卡片数量
        
    - 成功处理数量
        
    - 失败数量
        
    - 当前累计完成数量
        
7. 汇报完成后，再继续处理下一组，直到整个牌组处理完毕。
    

## 解析原则

1. 先把句子中几个主要部分拆开解释，给出它们在当前句子中的中文含义。
    
2. 然后指出这句话中**最值得学习的 1～2 个词、短语或固定搭配**。
    
3. 对这些重点内容适当解释词义、词性、固定搭配或常见用法。
    
4. 如有必要，可以给 1～2 个简单例句帮助理解。
    
5. 不需要系统分析所有语法，不需要复杂句法结构。
    
6. 不机械解释每一个单词，只解释真正有学习价值的部分。
    
7. 简单句保持简短，复杂句可以适当多解释。
    
8. 不设固定字数限制。
    
9. 使用中文解释，重要英语词汇和短语保留英文。
    
10. 不修改其他字段。
    
11. 如果【助记符】字段已有内容，则覆盖原内容。
    

## Anki 网页风格 / HTML 输出要求

【助记符】字段最终会直接显示在 Anki 卡片网页界面中，因此必须输出为 **Anki 可直接渲染的 HTML**。

请严格遵守以下格式要求：

1. **禁止使用 Markdown 语法。**
    
2. 不要输出 `**加粗**`、`*斜体*`、`# 标题`、Markdown 列表等内容。
    
3. 不要出现转义后的 Markdown 符号，例如：  
    `\*\*重点表达\*\*`
    
4. 加粗统一使用：  
    `<b>内容</b>`
    
5. 段落统一使用：  
    `<p>内容</p>`
    
6. 列表优先使用：  
    `<ul><li>内容</li></ul>`
    
7. 普通换行可以使用：  
    `<br>`
    
8. 中文释义、中文翻译等辅助内容可以使用：  
    `<span class="cn">中文内容</span>`
    
9. 重点词汇或重点短语可以使用：  
    `<span class="target-word">重点内容</span>`
    
10. 简短示例可以使用：  
    `<blockquote>示例内容</blockquote>`
    
11. 不要使用复杂 HTML，不要写内联 CSS。
    
12. 不要输出 `<style>`、`<script>`、JavaScript 或完整网页结构。
    
13. 不要输出 `<html>`、`<head>`、`<body>` 标签。
    
14. 只输出适合直接写入【助记符】字段的 HTML 片段。
    
15. 不要使用 Markdown 代码块包裹 HTML，例如不要输出 ```html。
    
16. HTML 标签必须完整、正确闭合，避免影响 Anki 卡片显示。
    
17. 输出应简洁、清晰，适合手机和电脑端阅读。
    

## 推荐 HTML 输出结构

例句：

The company's characteristic approach to problem-solving is highly valued.

【助记符】字段建议生成：

<p>这句话表示：公司的这种典型解决问题的方式非常受重视。</p>

<ul> <li><b>The company's</b> = 公司的</li> <li><b>characteristic approach</b> = 有特色的 / 典型的做法、方式</li> <li><b>to problem-solving</b> = 对解决问题这件事 / 在解决问题方面</li> <li><b>is highly valued</b> = 非常受重视 / 被高度认可</li> </ul>

<p>这里最值得注意的是 <span class="target-word">characteristic approach</span>。</p>

<p><b>characteristic</b> 不只是“特征”这个名词的意思，它作形容词时表示“典型的、有特色的、独特的”。</p>

<blockquote> This is a characteristic feature of the system.<br> <span class="cn">这是这个系统的一个典型特征。</span> </blockquote>

<p>另一个常见搭配是 <span class="target-word">approach to + 名词 / doing</span>，表示“做某事的方法 / 思路”。</p>

<blockquote> approach to problem-solving<br> <span class="cn">解决问题的方法 / 思路</span><br><br>

approach to learning English<br>  
<span class="cn">学习英语的方法</span>

</blockquote>
