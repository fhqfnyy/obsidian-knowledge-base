法语里的“物主代词/物主限定词”最容易混淆。我把两套都给你列出来。日常学习中，最先要掌握的是 **mon / ma / mes** 这一套。

### 一、物主限定词 adjectifs possessifs

相当于英语的 **my, your, his/her, our, your, their**，后面必须跟名词。

|所有人|阳性单数|阴性单数|复数|中文|
|---|---|---|---|---|
|je 我|**mon**|**ma**|**mes**|我的|
|tu 你|**ton**|**ta**|**tes**|你的|
|il / elle 他/她|**son**|**sa**|**ses**|他/她的|
|nous 我们|**notre**|**notre**|**nos**|我们的|
|vous 你们/您|**votre**|**votre**|**vos**|你们的/您的|
|ils / elles 他们/她们|**leur**|**leur**|**leurs**|他们/她们的|

例如：

- **mon livre** = 我的书（livre 阳性）
- **ma voiture** = 我的车（voiture 阴性）
- **mes amis** = 我的朋友们
- **ton téléphone** = 你的手机
- **sa maison** = 他/她的房子
- **notre travail** = 我们的工作
- **vos enfants** = 你们的孩子
- **leurs voitures** = 他们的汽车

这里有一个非常重要的规律：

**物主词的形式取决于“后面的东西”，而不是拥有者的性别。**

比如：

- **Paul aime sa voiture.**  
    Paul 喜欢他的车。

虽然 Paul 是男性，但 voiture 是阴性，所以用 **sa**。

- **Marie aime son travail.**  
    Marie 喜欢她的工作。

Marie 是女性，但 travail 是阳性，所以用 **son**。

### 二、元音前的特殊情况：ma / ta / sa → mon / ton / son

如果阴性名词以**元音或哑音 h** 开头，为了发音顺畅：

|正常形式|元音前|
|---|---|
|ma|**mon**|
|ta|**ton**|
|sa|**son**|

例如：

- **mon amie** = 我的女性朋友
- **ton école** = 你的学校
- **son idée** = 他/她的想法

虽然 **amie / école / idée 都是阴性**，仍然使用 mon / ton / son。

例如：

**C'est mon amie.**  
这是我的女性朋友。

不能说 ~~ma amie~~。

### 三、真正的“物主代词” pronoms possessifs

这一套相当于英语：

**mine, yours, his, hers, ours, theirs**

它可以**直接代替名词**。

|所有人|阳单|阴单|阳复|阴复|
|---|---|---|---|---|
|我的|**le mien**|**la mienne**|**les miens**|**les miennes**|
|你的|**le tien**|**la tienne**|**les tiens**|**les tiennes**|
|他/她的|**le sien**|**la sienne**|**les siens**|**les siennes**|
|我们的|**le nôtre**|**la nôtre**|**les nôtres**|**les nôtres**|
|你们的/您的|**le vôtre**|**la vôtre**|**les vôtres**|**les vôtres**|
|他们的|**le leur**|**la leur**|**les leurs**|**les leurs**|

对比一下最容易理解：

**C'est mon livre.**  
这是**我的书**。

**C'est le mien.**  
这是**我的（那个）**。

再比如：

**Ta voiture est nouvelle. La mienne est vieille.**  
你的车是新的，我的是旧的。

这里：

- **ta voiture** = 你的车
- **la mienne** = 我的车

因为 voiture 是阴性，所以是 **la mienne**。

### 最值得先记住的表

如果你现在主要学 A1–B1，我建议首先把这一组背熟：

|我|你|他/她|我们|你们|他们|
|---|---|---|---|---|---|
|mon|ton|son|notre|votre|leur|
|ma|ta|sa|notre|votre|leur|
|mes|tes|ses|nos|vos|leurs|

可以把前三组按规律一起记：

**mon → ton → son**  
**ma → ta → sa**  
**mes → tes → ses**

后面三组：

**notre → votre → leur**  
**nos → vos → leurs**

这样记会比一个一个单独背容易很多。
