法语规则动词的现在时变位其实比较简单。**规则动词主要分为三类：-er、-ir、-re**。其中 **-er 动词最重要、最常用**。

## 1. 第一组：-er 动词

以 **parler（说）** 为例。

|人称|词尾|parler 变位|发音|
|---|--:|---|---|
|je|**-e**|je **parle**|/paʁl/|
|tu|**-es**|tu **parles**|/paʁl/|
|il / elle|**-e**|il **parle**|/paʁl/|
|nous|**-ons**|nous **parlons**|/paʁlɔ̃/|
|vous|**-ez**|vous **parlez**|/paʁle/|
|ils / elles|**-ent**|ils **parlent**|/paʁl/|

### 记忆公式

**去掉 -er + 词尾：**

> **-e / -es / -e / -ons / -ez / -ent**

例如：

**aimer（喜欢）**

|人称|变位|
|---|---|
|je|j'**aime**|
|tu|**aimes**|
|il / elle|**aime**|
|nous|**aimons**|
|vous|**aimez**|
|ils / elles|**aiment**|

---

## 2. 第二组：规则 -ir 动词

以 **finir（完成）** 为例。

|人称|词尾|finir 变位|发音|
|---|--:|---|---|
|je|**-is**|je **finis**|/fini/|
|tu|**-is**|tu **finis**|/fini/|
|il / elle|**-it**|il **finit**|/fini/|
|nous|**-issons**|nous **finissons**|/finisɔ̃/|
|vous|**-issez**|vous **finissez**|/finise/|
|ils / elles|**-issent**|ils **finissent**|/finis/|

### 记忆公式

> **-is / -is / -it / -issons / -issez / -issent**

例如：

**choisir（选择）**

> je choisis  
> tu choisis  
> il choisit  
> nous choisissons  
> vous choisissez  
> ils choisissent

⚠️ 注意：**不是所有 -ir 动词都是这一规则。**

例如：

- partir → je pars
    
- venir → je viens
    
- dormir → je dors
    

这些属于不规则或特殊变化，需要单独记忆。

---

## 3. 第三组：-re 动词

以比较规则的 **vendre（卖）** 为例。

|人称|词尾|vendre 变位|发音|
|---|--:|---|---|
|je|**-s**|je **vends**|/vɑ̃/|
|tu|**-s**|tu **vends**|/vɑ̃/|
|il / elle|**—**|il **vend**|/vɑ̃/|
|nous|**-ons**|nous **vendons**|/vɑ̃dɔ̃/|
|vous|**-ez**|vous **vendez**|/vɑ̃de/|
|ils / elles|**-ent**|ils **vendent**|/vɑ̃d/|

### 记忆公式

> **-s / -s / — / -ons / -ez / -ent**

---

# 三类规则动词放在一起

这个表非常值得直接背下来：

|人称|**-er**|**-ir**|**-re**|
|---|---|---|---|
|je|**-e**|**-is**|**-s**|
|tu|**-es**|**-is**|**-s**|
|il / elle|**-e**|**-it**|**—**|
|nous|**-ons**|**-issons**|**-ons**|
|vous|**-ez**|**-issez**|**-ez**|
|ils / elles|**-ent**|**-issent**|**-ent**|

### 最重要的规律

你可以先把它压缩成：

**-ER：**

> e → es → e → ons → ez → ent

**-IR：**

> is → is → it → issons → issez → issent

**-RE：**

> s → s → — → ons → ez → ent

---

## 4. 初学阶段建议优先掌握 -ER

因为 **-er 动词数量非常多**，而且变化最简单。

例如：

|原形|中文|je 形式|
|---|---|---|
|parler|说|je parle|
|aimer|喜欢|j'aime|
|travailler|工作|je travaille|
|habiter|居住|j'habite|
|regarder|看|je regarde|
|écouter|听|j'écoute|
|chercher|寻找|je cherche|
|demander|请求、询问|je demande|
|travailler|工作|je travaille|
|étudier|学习|j'étudie|
|jouer|玩、演奏|je joue|
|marcher|走路|je marche|

你会发现，**只要掌握 `-er → e/es/e/ons/ez/ent`，就能直接变出大量动词。**

还有一个非常重要的现象：

> **je parle / tu parles / il parle / ils parlent**

这四个形式**发音完全一样**：

> /paʁl/

所以学习法语动词时，**不能只靠听发音判断主语，要同时熟悉“主语 + 变位拼写”**。

可以。法语动词学习不能只掌握“现在时”，还需要建立一个**时态体系**。不过初学阶段不需要一次把所有时态都背完。

先用规则动词 **parler（说）** 来看最常用的时态。

## 一、法语常用时态总览

|时态|法语名称|主要用途|parler 示例|
|---|---|---|---|
|**现在时**|Présent|正在发生、习惯、事实|je parle|
|**复合过去时**|Passé composé|已经完成的过去动作|j'ai parlé|
|**未完成过去时**|Imparfait|过去习惯、背景、持续状态|je parlais|
|**简单将来时**|Futur simple|将来会发生|je parlerai|
|**近将来时**|Futur proche|马上/计划要做|je vais parler|
|**愈过去时**|Plus-que-parfait|过去的过去|j'avais parlé|
|**条件式现在时**|Conditionnel présent|假设、愿望、委婉|je parlerais|
|**虚拟式现在时**|Subjonctif présent|必要、愿望、情感等|que je parle|
|**简单过去时**|Passé simple|文学、正式书面语|je parlai|

对于 **A1-B1**，最重要的是前 **6 个**。

---

# 二、Présent 现在时

以 **parler** 为例：

|人称|变位|
|---|---|
|je|**parle**|
|tu|**parles**|
|il / elle|**parle**|
|nous|**parlons**|
|vous|**parlez**|
|ils / elles|**parlent**|

规律：

> **-e / -es / -e / -ons / -ez / -ent**

例如：

> Je parle français.  
> 我说法语。

---

# 三、Passé composé 复合过去时

这是**日常法语最重要的过去时**之一。

结构：

> **avoir / être + 过去分词**

parler 的过去分词：

> parler → **parlé**

所以：

|人称|变位|
|---|---|
|j'|**ai parlé**|
|tu|**as parlé**|
|il / elle|**a parlé**|
|nous|**avons parlé**|
|vous|**avez parlé**|
|ils / elles|**ont parlé**|

例如：

> J'ai parlé avec lui.  
> 我跟他谈过了。

### 规则 -er 动词的过去分词

通常：

> **-er → -é**

例如：

|原形|过去分词|
|---|---|
|parler|parlé|
|aimer|aimé|
|travailler|travaillé|
|regarder|regardé|
|écouter|écouté|

---

# 四、Imparfait 未完成过去时

主要表示：

- 过去的习惯
    
- 过去正在进行的状态
    
- 过去的背景
    
- “以前经常……”
    

例如：

> Quand j'étais jeune, je travaillais beaucoup.  
> 我年轻的时候，经常工作很多。

以 **parler** 为例：

|人称|变位|
|---|---|
|je|**parlais**|
|tu|**parlais**|
|il / elle|**parlait**|
|nous|**parlions**|
|vous|**parliez**|
|ils / elles|**parlaient**|

### 规律

拿 **nous 现在时**：

> nous parl**ons**

去掉 **-ons**：

> parl-

然后加：

> **-ais / -ais / -ait / -ions / -iez / -aient**

所以：

**parl + ais**

→ je parlais

**parl + ait**

→ il parlait

---

# 五、Futur simple 简单将来时

表示将来：

> 我将说  
> 我以后会说

规则 **-er / -ir** 动词：

> **原形 + 词尾**

parler：

|人称|变位|
|---|---|
|je|**parlerai**|
|tu|**parleras**|
|il / elle|**parlera**|
|nous|**parlerons**|
|vous|**parlerez**|
|ils / elles|**parleront**|

### 词尾

> **-ai / -as / -a / -ons / -ez / -ont**

例如：

> Je parlerai demain.  
> 我明天会说。

---

# 六、Futur proche 近将来时

这个非常重要，而且非常简单。

结构：

> **aller + 动词原形**

例如：

> Je vais parler.  
> 我要说。

|人称|结构|
|---|---|
|je|**vais parler**|
|tu|**vas parler**|
|il / elle|**va parler**|
|nous|**allons parler**|
|vous|**allez parler**|
|ils / elles|**vont parler**|

例如：

> Je vais travailler demain.  
> 我明天要工作。

这个时态在日常口语中非常常见。

---

# 七、Plus-que-parfait 愈过去时

表示：

> **过去某个时间之前已经发生的事情**

中文可以理解为：

> “已经……了”

结构：

> **avoir / être 的未完成过去时 + 过去分词**

例如：

> J'avais parlé.  
> 我已经说过了。

|人称|变位|
|---|---|
|je|**avais parlé**|
|tu|**avais parlé**|
|il / elle|**avait parlé**|
|nous|**avions parlé**|
|vous|**aviez parlé**|
|ils / elles|**avaient parlé**|

例如：

> Quand il est arrivé, j'avais déjà parlé avec Paul.

他到达的时候，我已经和 Paul 谈过了。

---

# 八、Conditionnel présent 条件式现在时

表示：

- 假设
    
- 愿望
    
- 委婉请求
    
- “会……”
    
- “想……”
    

例如：

> Je voudrais un café.

我想要一杯咖啡。

**parler：**

|人称|变位|
|---|---|
|je|**parlerais**|
|tu|**parlerais**|
|il / elle|**parlerait**|
|nous|**parlerions**|
|vous|**parleriez**|
|ils / elles|**parleraient**|

它的词尾实际上和 **imparfait** 一样：

> **-ais / -ais / -ait / -ions / -iez / -aient**

但前面使用**将来时词干**。

---

# 九、把这些时态放在一起

用 **parler** 最直观：

|人称|现在|复合过去|未完成过去|简单将来|近将来|
|---|---|---|---|---|---|
|je|parle|j'ai parlé|parlais|parlerai|vais parler|
|tu|parles|as parlé|parlais|parleras|vas parler|
|il|parle|a parlé|parlait|parlera|va parler|
|nous|parlons|avons parlé|parlions|parlerons|allons parler|
|vous|parlez|avez parlé|parliez|parlerez|allez parler|
|ils|parlent|ont parlé|parlaient|parleront|vont parler|

# 十、真正需要重点掌握的“变位逻辑”

你可以把法语时态理解成几个模块：

### ① 现在时

> **词干 + 现在时词尾**

parl + e  
parl + es  
parl + e  
parl + ons  
parl + ez  
parl + ent

---

### ② 未完成过去时

> **nous词干 + imparfait词尾**

parl + ais  
parl + ais  
parl + ait  
parl + ions  
parl + iez  
parl + aient

---

### ③ 简单将来时

> **原形 + futur词尾**

parler + ai  
parler + as  
parler + a  
parler + ons  
parler + ez  
parler + ont

---

### ④ 条件式

> **将来时词干 + 未完成过去时词尾**

parler + ais  
parler + ais  
parler + ait  
parler + ions  
parler + iez  
parler + aient

---

### ⑤ 复合过去时

> **助动词 + 过去分词**

j'**ai** + **parlé**

---

### ⑥ 近将来

> **aller + 原形**

je **vais** + **parler**

---

## 最后给你一个学习顺序

如果你现在正在系统学法语，我建议按这个顺序：

**第一阶段：**

> Présent 现在时  
> ↓  
> Futur proche 近将来  
> ↓  
> Passé composé 复合过去时

**第二阶段：**

> Imparfait 未完成过去时  
> ↓  
> Futur simple 简单将来时  
> ↓  
> Plus-que-parfait 愈过去时

**第三阶段：**

> Conditionnel 条件式  
> ↓  
> Subjonctif 虚拟式  
> ↓  
> Passé simple 简单过去时

这样学会发现，**法语并不是每个时态都要重新背一套完全不同的东西**。很多时态实际上是由“词干 + 固定词尾”组合出来的。尤其是 **imparfait、futur、conditionnel**，掌握它们之间的关系以后，变位会简单很多。
