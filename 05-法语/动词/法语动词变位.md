# 一、法语动词变位的基本要素

法语动词变位主要受 **四个因素**影响：

1. **人称（personne）**
    
2. **数（单数 / 复数）**
    
3. **时态（temps）**
    
4. **语气（mode）**
    

---

# 二、六个基本人称

法语动词必须和主语一致：

|人称|法语|中文|
|---|---|---|
|第一人称单数|je|我|
|第二人称单数|tu|你|
|第三人称单数|il / elle / on|他 / 她 / 人们|
|第一人称复数|nous|我们|
|第二人称复数|vous|你们 / 您|
|第三人称复数|ils / elles|他们 / 她们|

---

# 三、三类规则动词

法语规则动词根据 **原形结尾** 分为三类：

|类型|结尾|例子|中文|
|---|---|---|---|
|第一组|-er|parler|说话|
|第二组|-ir|finir|完成|
|第三组|-re|vendre|卖|

第三组通常是不规则动词。

---

# 四、第一组动词变位（最常见）

以 **parler（说话）** 为例：

### 现在时（présent）

|人称|变位|
|---|---|
|je|parle|
|tu|parles|
|il / elle|parle|
|nous|parlons|
|vous|parlez|
|ils|parlent|

规律：

```
去掉 -er
加词尾
-e
-es
-e
-ons
-ez
-ent
```

---

# 六、第三组动词（不规则）

例如：**prendre（拿）**

|人称|变位|
|---|---|
|je|prends|
|tu|prends|
|il|prend|
|nous|prenons|
|vous|prenez|
|ils|prennent|

这一组没有统一规律，需要记忆。

---

# 七、常见时态

法语常用时态：

|时态|法语|用途|
|---|---|---|
|现在时|présent|现在发生|
|复合过去时|passé composé|已经发生|
|未完成过去时|imparfait|过去习惯|
|简单将来时|futur simple|将来|
|近未来|futur proche|马上要发生|

---

# 八、复合过去时例子

动词：**manger（吃）**

结构：

```
助动词 + 过去分词
avoir / être + participe passé
```

例子：

|人称|句子|
|---|---|
|j'ai mangé|我吃了|
|tu as mangé|你吃了|
|il a mangé|他吃了|
|nous avons mangé|我们吃了|
|vous avez mangé|你们吃了|
|ils ont mangé|他们吃了|

---

# 九、一个简单总结

法语动词变位 =

```
动词词干 + 词尾
```

变化取决于：

```
人称
时态
语气
动词类型
```
