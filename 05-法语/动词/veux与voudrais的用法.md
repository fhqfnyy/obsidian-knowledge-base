可以。你刚才问到的其实都是 **vouloir（想要、愿意）**，只是时态不同：

| 人称    | 直陈式现在时 Présent    | 中文          | 条件式现在时 Conditionnel présent | 中文               |
| ----- | ----------------- | ----------- | --------------------------- | ---------------- |
| je    | **je veux**       | 我想要         | **je voudrais**             | 我想要 / 我希望（更礼貌）   |
| tu    | **tu veux**       | 你想要         | **tu voudrais**             | 你想要 / 你愿意        |
| il    | **il veut**       | 他想要         | **il voudrait**             | 他想要 / 他希望        |
| elle  | **elle veut**     | 她想要         | **elle voudrait**           | 她想要 / 她希望        |
| on    | **on veut**       | 我们想要 / 人们想要 | **on voudrait**             | 我们想要 / 人们希望      |
| nous  | **nous voulons**  | 我们想要        | **nous voudrions**          | 我们想要 / 我们希望      |
| vous  | **vous voulez**   | 您想要 / 你们想要  | **vous voudriez**           | 您想要 / 您愿意 / 你们想要 |
| ils   | **ils veulent**   | 他们想要        | **ils voudraient**          | 他们想要 / 他们希望      |
| elles | **elles veulent** | 她们想要        | **elles voudraient**        | 她们想要 / 她们希望      |

最重要的是区分这两个：

**Je veux** = 我想要  
语气比较直接。

**Je voudrais** = 我想要 / 我希望  
语气更礼貌，日常交流里非常常用。

例如：

|法语|中文|
|---|---|
|**Je veux un café.**|我要一杯咖啡。|
|**Je voudrais un café.**|我想要一杯咖啡。|
|**Tu veux venir ?**|你想来吗？|
|**Tu voudrais venir ?**|你愿意来吗？|
|**Vous voulez boire quelque chose ?**|您想喝点什么吗？|
|**Vous voudriez boire quelque chose ?**|您想喝点什么吗？（更委婉）|

你可以简单记成：

**veux / veut / voulons / voulez / veulent → “想要”**  
**voudrais / voudrait / voudrions / voudriez / voudraient → “想要，不过更礼貌、更委婉”**

其中你日常最值得先记住的是 **je veux、tu veux、il veut、vous voulez、je voudrais、vous voudriez**。
