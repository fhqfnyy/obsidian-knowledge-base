法语里“来”最常用的是 **venir**。它也是一个很重要的不规则动词。

### Venir 常用变位表

| 时态                              | 人称             | 变位              | 中文        |
| ------------------------------- | -------------- | --------------- | --------- |
| **现在时 Présent**                 | je             | **viens**       | 我来        |
|                                 | tu             | **viens**       | 你来        |
|                                 | il / elle / on | **vient**       | 他/她来      |
|                                 | nous           | **venons**      | 我们来       |
|                                 | vous           | **venez**       | 你们来 / 您来  |
|                                 | ils / elles    | **viennent**    | 他们/她们来    |
| **未完成过去时 Imparfait**            | je             | **venais**      | 我那时来 / 常来 |
|                                 | tu             | **venais**      | 你那时来      |
|                                 | il / elle / on | **venait**      | 他/她那时来    |
|                                 | nous           | **venions**     | 我们那时来     |
|                                 | vous           | **veniez**      | 你们那时来     |
|                                 | ils / elles    | **venaient**    | 他们那时来     |
| **简单将来时 Futur simple**          | je             | **viendrai**    | 我将来       |
|                                 | tu             | **viendras**    | 你将来       |
|                                 | il / elle / on | **viendra**     | 他/她将来     |
|                                 | nous           | **viendrons**   | 我们将来      |
|                                 | vous           | **viendrez**    | 你们将来      |
|                                 | ils / elles    | **viendront**   | 他们将来      |
| **条件式现在时 Conditionnel présent** | je             | **viendrais**   | 我会来       |
|                                 | tu             | **viendrais**   | 你会来       |
|                                 | il / elle / on | **viendrait**   | 他/她会来     |
|                                 | nous           | **viendrions**  | 我们会来      |
|                                 | vous           | **viendriez**   | 你们会来      |
|                                 | ils / elles    | **viendraient** | 他们会来      |

### 复合过去时 Passé composé

**venir** 和 **aller** 一样，也用 **être**：

|人称|变位|
|---|---|
|je|**suis venu(e)**|
|tu|**es venu(e)**|
|il|**est venu**|
|elle|**est venue**|
|nous|**sommes venu(e)s**|
|vous|**êtes venu(e)(s)**|
|ils|**sont venus**|
|elles|**sont venues**|

例如：

- **Je viens ici tous les jours.** 我每天都来这里。
- **Il vient demain.** 他明天来。
- **Nous viendrons demain.** 我们明天会来。
- **Elle est venue hier.** 她昨天来了。

### 命令式 Impératif

|人称|变位|中文|
|---|---|---|
|tu|**Viens !**|来！|
|nous|**Venons !**|我们来吧|
|vous|**Venez !**|来吧 / 请过来|

你前面刚学了 **aller（去）**，可以这样一起记：

|去 aller|来 venir|
|---|---|
|je **vais**|je **viens**|
|tu **vas**|tu **viens**|
|il **va**|il **vient**|
|nous **allons**|nous **venons**|
|vous **allez**|vous **venez**|
|ils **vont**|ils **viennent**|

这两个动词建议成对记忆：**aller = 去，venir = 来**。
