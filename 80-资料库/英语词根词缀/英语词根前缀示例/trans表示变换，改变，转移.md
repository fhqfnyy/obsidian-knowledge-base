# trans	 表示“变换，改变，转移”
1. tranplant 	移植（trans+plant 种→转移过去→移植） 
2. transaction 	交易；办理（trans+action 行动→交换行动→交易） 
3. transcribe	 抄写，转录（trans+scribe 写→把写的东西移到〔另一张纸上〕→抄写） 
4. transfigure	 改观；变形（trans+figure 形状→改变形状） 
5. transfuse	 输血；充满（trans+fuse 流→〔血〕流过去→输血）
6. transitory	 短暂的（trans+it 走＋ory→走过就变→输血） 
7. transmogrify 	变得古怪，变形（trans+mogr 怪形状＋ify→变成怪形状）
