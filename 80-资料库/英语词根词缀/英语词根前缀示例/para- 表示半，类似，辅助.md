# para- 	表示“半，类似，辅助” 
1. parastatal 	半官方的（para+sttal 国家的） 
2. parapolitical 	半政治的（para+political 政治的） 
# para	表示“在旁边” 
1. paradigm 	范例，示范（para+digm 显示→在旁边显示给〔别人〕→示范） 
2. paradox	 矛盾的说法（para+dox 观点→观点边上有观点→矛盾）
3. paragon 	典范（para+gon 角→旁边顶尖人物→典范） 
4. paralogism 	不合逻辑的推论（para+logism 逻辑→在逻辑边上→不是逻辑） 
# para	表示“降落伞” 
1. parachute	 降落伞（para+chute 降下） 
2. paradrop 	空投，空降（para+drop 扔下）
