# se-	表示“分开，离开，区别开”
1. secede 	正式退出（组织）（se+cede 走→走开→退出） 
2. seclude 	和别人隔离；隐居（se+clude 关闭→分开关→隐居的）
3. secrete	分泌；藏匿（se+crete 分辨→分辨开→分泌；藏起来；）
4. sedition 	煽动叛乱（sed=se+it 走＋ion→分开走→煽动叛乱） 
5. seduce 	勾引，诱惑（se+duce 引→引开→勾引别人） 
6. segregate 	隔离（se+greg 群＋ate→和人群分开→隔离） 
7. sever 	切断；脱离（se+ver 分开→分离开→切断） 
8. select 	选出（se+lect 选→选出分开）
