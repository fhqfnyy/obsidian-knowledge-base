# post-	表示“在后面” 
1. postwar	 战后的（post+war 战争） 
2. postpone 	推迟（post+phone 放→放到后面→推迟） 
3. postgraduate 	大学毕业后的（post+graduate 毕业） 
4. postface	 刊后语（post+face 脸；前面→后面的脸→刊后语） 
5. posterior 	较后的（post＋erity 表名词→后面的人→子孙） 
# post	表示“邮件，邮政”
1. postage 	邮资（post+age 钱；状态） 
2. postoffice 	邮局（post+office 办公室） 
3. postcard 	明信片（post+card 卡片） 
4. postal 	邮政的（post+al）
